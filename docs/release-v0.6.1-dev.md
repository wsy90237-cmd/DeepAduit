# DeepAudit 0.6.1 开发预览

本版本按开发需求提供未编译的源码运行包，自带 Windows x64 Python 和必要运行依赖。正式客户 EXE 仍采用 Nuitka 流程。

- 修复 Windows 对 UTF-8/LF 启动脚本的错误解析：两个 CMD 入口使用 ASCII 与 CRLF，路径始终加引号。
- 启动失败时保留临时日志；窗口入口显示错误和日志路径，诊断入口保留控制台输出。
- 源码和开发包共用入口。开发包优先使用包内运行环境，不依赖旧 `.venv` 或本机 Python 安装路径。
- 新增 `tools/build_dev.py`，仅复制运行库、已知依赖和应用源码，保留第三方许可证；自动执行合成数据离线自检、记录源码提交和依赖版本，生成 ZIP 与 SHA-256。
- 延续 0.6.0 的一级科目底稿、二级明细、AI 文字和变动说明、独立金额核对及截止凭证抽样。

开发包不含本机设置、API Key、账套、客户模板、项目资料或测试日志。完整证据勾稽、附注和报告生成尚未完成；WPS 另存与真实账套操作不属于此次启动修复验证。

验证：544 项合成单元测试通过；修复后的 `DeepAudit-trial.cmd --selftest` 通过。开发打包脚本还会使用包内 Python 再运行一次离线自检，成功后才生成 ZIP。
