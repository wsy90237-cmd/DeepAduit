# DeepAudit 模型与知识库接入

适用版本：0.5.0。模型提供推理与建议，知识库提供可核对的参考文字，账套提供本地金额事实；三者凭证与用途分开。

## 配置模型

1. 打开应用右上角「AI 设置」。默认 API 地址为 `https://api.deepseek.com`；兼容服务可填写自己的 HTTPS 基础地址（需要时包含 `/v1`，不要填 `/chat/completions`）。
2. 在软件窗口输入该服务的 API Key。已保存的密钥不会回显；同一服务留空可保留原 Key。切换地址必须重新输入对应服务的 Key。
3. 点击「验证凭证 / 获取模型」，从该账户返回的列表中选择模型，也可手填模型 ID。这一步只调用 `/models`，不能证明对话能力可用。
4. 按需点击「验证对话能力」。确认后发送固定 JSON 测试问题，不含项目资料，但会使用少量 API token。
5. 勾选启用并「加密保存」。保存不强制要求联网测试；未经验证的配置能否使用以实际请求为准。

兼容服务需要 Bearer 鉴权、GET `/models`、POST `/chat/completions`，支持 JSON 对象响应、system 消息及本版使用的参数；不是任意 API 都能直接接入。账号权限、模型价格与可用模型由服务方决定。默认模型为离线候选，优先使用实际模型列表。

Key 只向填写的 HTTPS 服务发送；重定向会被拒绝。请先核对服务域名，不要向不可信地址配置凭证。密钥不能发到聊天、源代码、截图或测试报告中。

## 接入自己的 ima

现有 ima 账号和“关注的知识库”不能直接转换成本地资料库。当前官方开放接口提供知识库搜索和资料搜索，是否可读由接口实际返回的权限决定。

1. 在 [ima 官方开放接口页](https://ima.qq.com/agent-interface) 自行查看开通条件、取得 Client ID 与 API Key；登录、创建凭证由你在官方页面完成。
2. 在 DeepAudit「财会知识库 → 配置 ima 连接」填这两项并加密保存。它们与模型 API Key 不通用。
3. 输入库名，点击「搜索库名」，从结果选择库；如果已有官方库 ID，可直接填写。分页未结束时可点击「更多库」。
4. 将来源选择为「ima 知识库」，输入具体检索词（例如需要核查的会计事项），点击「检索资料」。更多结果可翻页。
5. 双击阅读命中片段，选择 1–5 个含正文的结果，点击「选用为本次依据」；或者选择 TB、附注、底稿、报告并点击「Agent 检索并复核」。

本版固定访问 `https://ima.qq.com/openapi/wiki/v1/`，使用官方 `ima-openapi-clientid`、`ima-openapi-apikey` 请求头。仅调用只读搜索接口，分页标志不完整时报告错误。返回 110030 时显示无权访问；不会当作“空库”或自动绕过权限。仅返回标题的结果不能作为正文依据。

ima 搜索仅接收你填写的查询词与库 ID，不上传账套、TB 或待复核文档。检索词本身也会发送到 ima，请自行控制其中的客户信息。结果是搜索命中片段，不代表已取得整篇原文或完整知识库。本版不自动下载临时授权链接、不抓登录 Cookie、不做整库导出。

官方协议依据：[ima 开放接口](https://ima.qq.com/agent-interface) 提供的 [ima-skills 1.1.10 官方文档包](https://app-dl.ima.qq.com/skills/ima-skills-1.1.10.zip) 中 `knowledge-base/references/api.md`。本项目仅据此实现客户端，没有安装或运行该压缩包中的脚本。

## 没有 ima 接口权限时

将自己有权使用的资料另存为 TXT、Markdown、DOCX 或带文字层 PDF，然后「导入本地资料」。无法导出或未获授权的关注库，不应通过抓取方式复制。

单份最多 12 MB、30 万字符；PDF 最多 200 页，不支持加密 PDF、扫描 OCR、图片或版式理解。单次最多导入 10 份，本地库最多 200 份。按原文件 SHA-256 去重，不更改原文件。

本地按关键词和中文相邻词检索，每次最多返回 8 个资料片段，不是语义向量搜索。建议使用具体事项词，而不是整段提问。缓存保存标题、原路径、文字和内容哈希；修改原文件后需重新导入，旧内容不会自动更新。库内暂未提供删除和版本管理页面。

## Agent 复核

先在「账套与 TB」完成取数和识别，再选用知识依据。复核附注、底稿或已有报告时，选择一份待复核文档；它不会自动成为知识库资料。页面显示当前文档及截取状态。

每次模型请求都会先显示目的 API 地址、模型、问题、历史和工作区资料。取消则不发送。当前每次最多 30 个目标字段、300 个候选科目，另附本地汇总事实；待复核文档最多 12000 字符，每次最多 5 份知识片段、每份最多 1500 字符。该范围不代表全表或完整账套，提示词也要求说明限制。

审计对话按本轮问题中的报表项目、科目名称或编码选取事实，短追问可沿用近期项目范围。相关项目原值、备抵与零变动科目仍会发送；变动前 40 项只是辅助排序，未进入摘要不表示科目不存在或为零。超过 300 条的范围明确显示截取；净额等汇总由本地计算。知识检索在请求预览之前完成，实际发送与预览一致。损益事实使用本期、上期与月份独立发生额，不以期末结转余额或借贷累计代替。

Agent 用 `[K1]` 等编号引用本次提供的材料。编号不存在或没有引用时提示并丢弃改动提案；即使编号存在，也不能自动证明引用支持该结论。生效日期、会计准则、行业、适用主体与原文仍须核对。外部文字视为参考数据，不能授予执行权；AI 不执行程序、签发报告或任意写文件。TB 来源建议经本地白名单校验并由使用者选择应用，金额仍由本地计算。

主体或期间变化会清除原知识选用与待复核文档；切换 TB 模板等参数使匹配和提案失效。知识依据变化会清空旧对话，避免 `[K1]` 在不同材料间错用。

## 本地保存及排障

- `%LOCALAPPDATA%\ZSZH-TB\connections.json`：模型、接口信息及 DPAPI 加密凭证。只能由可解密的 Windows 账户使用，不要复制到客户包。无新文件时兼容读取旧 `settings.json`；新配置不会覆盖旧文件。
- 同目录 `knowledge.sqlite3`：未加密的知识文字缓存。不会自动上传整库。保护文件访问权限，并按资料授权安排备份。
- 401/403：检查 Key、所属服务与账号权限；402/429：检查服务余额或频率；JSON 能力测试失败：检查模型是否支持本版参数。
- ima 无权或搜不到关注库：到官方核对接口范围与库授权，或导入有权取得的文件。不要把模型 Key 当作 ima Key。
- 扫描 PDF 无文字：先在本机做 OCR，再由你核对识别内容后导入。

本轮使用合成凭证与模拟接口验证协议、错误处理和引用边界，没有使用你的账号进行收费对话或实际 ima 权限联调。
