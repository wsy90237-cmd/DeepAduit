# DeepAudit v0.5.5 代码审查记录

日期：2026-11-02。由 GPT-6.1 Sol 完成源码自审、修复及修改后复核；未调用其他模型或独立评审者。范围包括匹配调用链、AI 请求与采纳、QA 脚本、写入保护和正式发布流程。本轮没有读取客户账套、发送客户数据或改变仓库可见性。

## 已确认并修复的问题

|级别|问题及影响|修复与验证|
|---|---|---|
|P1|AI 父子摘要累计全部后代，且缺失金额当零，可能错误声明父子相等或不等|只核对直接子级，余额统一借方方向；缺失、重复路径、级次或账套期间不一致及不可加总列示返回未知。覆盖多层、混合方向、反向余额、真实零及未知反例|
|P1|损益已结账时余额为零，复核筛选遗漏非零发生额；年初未分配利润也可能错用期末余额|复用本地字段度量取数，候选提供借贷发生额；补损益结账及年初余额测试|
|P1|QA 评测直接调用外部模型，且原填数仍进入请求，违背隐藏答案与请求预览约定|默认只生成包含目的服务、模型、用途及实际范围的预览；仅在明确提供相同预览 SHA-256 后发送；字段原填数先隐藏。范围或服务变化拒绝请求|
|P1|逐家脚本丢失审定/损益/主体等缓存字段，缓存键不含期间账套，且可能复用过期数据或任取同名主体|完整保存 LedgerRow；键绑定完整项目目录、主体、年月及账套；每轮重新读取一致副本，旧缓存缺字段不可采纳；多项同名主体待核对|
|P2|AI 返回同一目标多次会导致界面重复行报错；返回结构缺少类型验证|拒绝重复目标及非列表结构，整批不采纳；覆盖错误结构、重复和正常返回|
|P2|QA 将原填空白判为误填，公式重复计数，单位容限及跨模板比较口径不一致|原填空白和缺来源单列待核对；公式计数一次；差额折算为元；跨模板比较同时绑定父级、度量、方向、分项与来源范围。结果保存至忽略目录|
|P1|发布自检遗漏 papers、skills；仅检查返回模块为真，未核对完整集合；构建后才记录源码版本|明确校验全部17个业务模块及真实布尔值；拒绝未提交源码，构建前后确认同一干净版本；覆盖缺模块、字符串真值及构建中版本变化|
|P2|文档仍称仓库私有，且将构建产物与正式 Release 混同|按当前公开状态修正文档，明确构建成功后还需草稿上传、下载校验和发布；不承诺源码保密或已签名|
|P2|首次云端运行在 cp1252 控制台输出中文预览时失败|预览库函数不再打印，命令行及CI明确使用UTF-8；补非Unicode控制台测试。发布流程只在计划改变时自动触发，避免工作流修改触发旧计划|

## 验证与发布条件

- 最终本机完整合成测试 **331项通过**，包含非Unicode控制台反例；云端结果另见关联构建。中间失败的反例和未冻结的测试不计作最终通过。
- v0.5.5 源码离线自检通过，涉及合成金额、DPAPI、日志、表头、知识、PDF、准备度及品牌资源。
- 正式包必须通过 GitHub Actions 的测试、MSVC/Nuitka 编译、17模块原生自检、PE检查，以及上传后四个发布文件的逐个下载哈希校验。最终证据以发布页 `BUILDINFO.json`、`SHA256SUMS.txt` 及关联运行记录为准。
- 原客户文件、账套、临时数据库、日志、预览与评测结果均不进入源码提交或发布附件。

## 未验证范围

本轮不重新运行客户十份 TB，不把上一轮结果冒充本版新增实测。没有真实外部模型联调，没有验证所有未知模板、所有界面操作、所有 Windows 本机策略或 pip wheel 安装。QA 引擎复算属于内部一致性检查，不代表独立审计证据；原填数一致也不能证明审计正确。上期审定、结转及调整证据不足的字段仍待复核。发布包未签名。
