# DeepAudit 0.6.4 本地开发版

修复 0.6.3 独立复核中发现的四项问题：

- 上年同编码的科目名称、层级归属或方向不一致时，上期金额与月份留空并提示确认；全年汇总不绕过已知身份冲突。
- 共享坏账准备先以完整总账核对总根和全部类别，再按已确认的类别子树取数，不把其他应收类别并入本册。
- 损益发生额按实际导出的多层明细逐级核对；已知差异不显示相符，缺少依据时保持未知，核对说明与实际执行栏一致。
- 取消“含序时账明细”后，抽凭及截止表不带出缓存凭证；重新勾选可使用已确认范围内的凭证。
