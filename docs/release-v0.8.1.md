# Attesta 0.8.1：界面自适应与模型连接排障

本版只做三件事：让界面在任意分辨率与缩放下都能完整操作、把「DeepSeek 用不了」变成可定位的结论、并给出可直接双击运行的 APP。业务算金额的代码未改。

## 一、模型连接：问题根因

先说明验证方法，再给结论，避免把环境问题当成代码问题。

**本机实测（同一份代码、同一把 Key）**：

| 检查 | 结果 |
| --- | --- |
| `GET /models` | HTTP 200，返回 `deepseek-flash`、`deepseek-v4-pro` |
| `POST /chat/completions`（`thinking: disabled`） | HTTP 200，`finish_reason=stop` |
| 对话能力验证 `probe_chat()` | 通过 |
| 生成速度 | 约 77 token/s |

结论：**请求构造、鉴权方式与返回解析都正确**，同事那边失败不在「接法」。

**根因（按影响排序）**

1. **固定 60 秒总超时**。`ai._request` 只有一个 `timeout=60`，连接、TLS、读取共用。底稿与分析请求 `max_tokens` 为 4096–6000，按实测 77 token/s，生成到 5000 token 时已需 65 秒——**长回答必然被掐断**，报错却是「无法连接模型服务或请求超时」。表现就是「连接测试能过、一做底稿就失败」。
2. **所有网络异常被合并成一句话**。DNS 失败、证书校验失败、代理未启动、超时全部落到同一个 `AIError`，底层原因被丢弃，同事无法判断该查网络还是查 Key。这是本次排查真正的障碍。
3. **PAC（自动配置脚本）不被解析**。`urllib` 只读环境变量与注册表里的静态代理；公司电脑大量用 PAC，程序于是直连，遇到 DNS 被解析到 `198.18.0.0/15`（代理 fake-IP）或防火墙拦 443 时，一律表现为超时。
4. **换机/换账户后 Key 无法解密**。Key 用 Windows DPAPI 按当前用户加密，配置跟着目录拷给同事后无法解密，需要重新输入——原提示没有说明这一步。

## 二、修复内容

- `tb_autofill/netdiag.py`（新增）：时间 / 代理 / DNS / TCP / TLS / 鉴权六段探测。仿 WinHTTP 解析 PAC，识别 fake-IP，读取证书颁发者与有效期，并对每段给出「下一步做什么」。可命令行运行：`.venv\Scripts\python.exe -m tb_autofill.netdiag https://api.deepseek.com`。
- `ai.py`：`_request` 改为「8 秒短超时预检 + 180 秒读取超时」，DNS/连接失败秒级返回；HTTP 状态码给出 404（地址填错）、407（代理认证）等新分支；异常按类型翻译成具体结论；仍保留重定向阻断与 Key 不回显（服务端回显内容里的 Key 会被打成 `***`）。
- `connections.py`：模型设置新增「网络诊断」按钮与结果窗口（可一键复制报告），连接对话框高度按内容收紧、宽度按屏幕收敛。
- 版本 0.8.1。

## 三、界面自适应

问题不在单个控件，而在一批写死的像素：窗口 `min(1480, 屏宽-90)`、`minsize(1000,620)`、侧栏 `place(x=207)` 的 1px 分隔线、`wraplength=820/1100`、Treeview 固定列宽与 `rowheight=30`。在 125%/150% 缩放下，Tk 的几何单位是物理像素而字号随 DPI 放大，这些常量必然导致裁切。

- `theme.py` 新增 `ui_scale() / px() / work_area() / fit_window() / wrap_to_parent() / fit_columns()`：所有设计像素统一按 DPI 折算，窗口与对话框以「扣掉任务栏的可用工作区」为上界并居中，`minsize` 不超过工作区。
- 主窗口：按工作区计算尺寸与最小尺寸；侧栏宽度与分隔线跟随 DPI（分隔线改用网格列，不再绝对定位）。
- 表单：主体/年度/截止月拆成两行（原来一行 8 个控件，150% 下「读取科目余额」被卡片裁掉）；填列期间与金额单位各占一行；表单区高度按「内容需要、可用高度、结果区保留 320px」三者取小，窗口变矮时表单先滚动，结果表与底部按钮始终可用。
- 结果表：列宽按窗口宽度等比分配；长文本 `wraplength` 跟随容器；详情行、退回提示等不再使用固定换行宽度。
- 对话框（主体选择、建议确认、抽凭、底稿、日志、来源）：统一 `fit_window`，并随内容收紧高度。

验证：1366×728（100%）、1330×692（150%）、1536×864 三档下无控件溢出，全部按钮可见；150% 下 1366×728 仍保留约 159px 表格高度。

## 四、APP 打包

`tools/build_app.py`（新增）用 PyInstaller 生成单文件 `dist\Attesta.exe`，内置 `tb_autofill/assets`（含内置知识库与索引清单），构建后自动跑 `--selftest` 并写出 `BUILDINFO.json / SHA256SUMS.txt / INSTALL.txt`。

该产物定位为**本机/内部试用版**：正式对外发布仍按 AGENTS.md 走 `tools/build_release.py` 的 Nuitka 原生编译（本机无 MSVC，未执行）。

## 五、未做与限制

- 未改动金额计算、匹配与底稿生成逻辑。
- 网络诊断只读本机配置，不写注册表、不修改代理。
- 模型输出质量仍须人工复核；连接诊断通过不等于模型回答正确。
