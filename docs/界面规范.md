# Attesta 界面规范

这份规范约束页面结构与文案密度，避免后续迭代把说明、状态和导航重新堆回界面。

## 页面只回答三件事

1. **现在是什么状态**：项目名、期间、账套、模板，或三项数字。
2. **下一步做什么**：一个主操作，按钮文字随状态变化（读取账套 / 选择模板 / 确认 N 项 / 核对 N 处差异 / 查看结果）。
3. **结果在哪里**：表格、导出动作或复核状态。

不写口号、产品介绍、操作教程和重复标题。如果删掉某段说明后页面看不懂，先改结构，而不是把说明加回来。

## 信息层级

- 页头只有页面名；全局动作最多一个（对话）。模型设置、日志校验放在「设置」页。
- 首页：项目名（衬线 32）→ 数据元信息（等宽 9）→ 三项指标 + 主操作。侧栏已经承担导航，首页不再重复模块入口。
- 数据页：动作在左上，结果占满剩余空间；状态文字只在有实际状态时出现，空状态不占位。
- 设置页：显示当前模型状态与三个动作，不解释安全承诺。

## 视觉令牌

所有颜色、字体与控件样式来自 `tb_autofill/theme.py`，页面不得硬编码色值。

- 画布 `#FEFAEF`，卡片 `#FFFFFF`，发丝线 `#E7DCC8`。
- 操作橙 `#B5520D`，只留给主按钮和当前导航项；亮橙只出现在图标。
- 正文与次要文字在画布、卡片上的对比度均 ≥ 4.5:1。
- 卡片用 1px 边框，不用阴影和渐变；动效只做 200ms 内的淡入，并尊重系统「减少动画」。

## 文案

- 按钮写动作，不写功能解释：`制作报表项目底稿`、`选择待复核底稿`、`复核底稿文字`。
- 状态写事实，不写建议：`确认 7 项`、`未配置模型`、`底稿：xxx.docx · 最多发送 12000 字符`。
- 不在主界面重复日志；运行日志按需从「设置 → 运行日志」打开。

## 自适应与自检

窗口与弹窗不得只在构造时量一次尺寸——`theme.fit_window()` 只够处理「打开时就知道多大」的静态页面。

- 弹窗必须常驻 `layout.LayoutGuard`：`<Configure>` 去抖后自检，按内容自动长高/加宽，最多自修 3 轮；
  达到工作区上限时改滚动，仍放不下就通过 `on_report` 在状态行给出可见告警，**不允许静默裁切**。
- 主体内容放进 `layout.scroll_host()`，底部操作栏用 `pack(side="bottom")` 放在滚动区之外，
  保证高级设置展开、字体回退、150% 缩放下按钮都点得到。
- 折叠/展开这类内容变化调用 `guard.refit()`，不要另写一套几何计算。
- `layout.diagnose()` 是通用体检：`clipped_bottom` / `clipped_right` / `content_overflow` /
  `content_underflow` / `wrap_too_wide`；内容超出可视高但滚动区已承接时报 `scrollable`，那是
  **可用状态，不是缺陷**。新增弹窗的验收标准是「展开全部内容后 `diagnose()` 为空，或仅剩
  `scrollable`」。
- `layout.autofit()` 以工作区为上界，**钉住窗口左上角**：内容变多就向下长，标题栏不跳；
  只有越出工作区才整体回收。位置基准用 `winfo_x/winfo_y`（外框坐标），不能用
  `winfo_rootx/winfo_rooty`（客户区坐标），否则每次自检窗口都会漂移。
- 滚动区内滚动用逐控件绑定，禁止 `bind_all` / `unbind_all` 接管 `<MouseWheel>`：
  那会连带清掉主页面的滚动绑定。
- 文本换行用 `wraplength` 跟随容器（`theme.wrap_to_parent`），不要写死到会超出窗口的宽度。

## 品牌与版权

- 产品名、公司、版权、文件说明、版本资源只从 `tb_autofill/brand.py` 取：`APP_NAME`、`COMPANY`、
  `COPYRIGHT`、`PRODUCT_NAME`、`FILE_DESCRIPTION`、`FOOTER_TEXT`。
- 界面页脚统一 `brand.FOOTER_TEXT`（`Attesta  vX.Y.Z · © WSY`）；导出 HTML 页脚同样带版本与版权。
- 打包必须写入版本资源：`tools/build_app.py` 传 `--version-file`，`tools/build_release.py` 传
  `--windows-company-name / --windows-copyright / --windows-product-name / --windows-file-description`。
  验收方式是右键 exe →「属性 → 详细信息」四项不为空。
- 消息框一律用 `tb_autofill/dialogs.py`（`from . import dialogs as messagebox`），禁止再调用原生
  `tkinter.messagebox`。

## 回归检查

- 运行 `tests/test_workspace.py`、`tests/test_theme.py`、`tests/test_brand.py`、
  `tests/test_layout.py`、`tests/test_dialogs.py`。
- 用 `tools/preview_ui.py --page <页面> --shot <png>` 截图核对：无裁切、无空标签、主操作在首屏。
- 新增用户可见名称必须引用 `APP_NAME` 或 `brand`，不要写死 `Attesta`。
