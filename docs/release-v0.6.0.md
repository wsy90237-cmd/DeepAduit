# DeepAudit v0.6.0（开发中，未发布）

当前可用范围为账套与 TB 处理、一级科目底稿草稿制作及 Excel 导出，以及现有附注、底稿、报告的文字辅助复核。按用户本轮明确要求恢复“制作底稿（一级科目）”入口；附注与报告生成、批量制作及完整证据勾稽仍待实现。

制作窗口只允许选择一级科目，下方列明直接所属二级科目的编码、名称与期末账面余额。每次导出一册，包含所选一级科目及二级明细，Excel 目录附二级清单；同属一个报表项目的其他一级科目不再混入。没有模型 Key 也可本地导出。AI 文字填写和专项表建议均先预览问题、实际数据与目的服务，取消不发送；来源变化时需重新预览。审定数与未知调整保持空白，草稿不能证明函证、监盘、凭证检查或项目复核已经执行。

2026-11-04 代码评审修正：

- 缺少映射、金额或存在混合账套时停止出表，不再任取第一科目或用零补未知值。
- 明细只核对直接子级；余额统一借方方向，避免多层重复累计和借贷混合误判。
- 账面数据不自动进入审定栏，未知调整与审定数保持空白，相关勾稽显示待复核。
- 账套及模型文本按文字写入，只有本地明确构造的公式可作为 Excel 公式。
- 修正披露合计列错位，来源变化时丢弃旧对话框结果；AI 上传预览期间来源变化则取消发送。
- 默认测试改为合成底稿，不再探测本机客户目录。原生自检与正式构建统一校验全部 24 个业务模块。

程序库快照保留现有来源记录（`assets/dxn-programs.json` 的 `generated_from` 和各条 `source`）；本轮没有重新采集原工具，也未核实其发行版本。这些内容是知识与程序参考，不是本项目审计证据。
