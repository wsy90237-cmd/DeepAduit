# DeepAudit 0.6.5 开发预览版（未编译）

本轮修正损益展示与审计问答的事实范围。源码与未编译开发包已发布到 GitHub：`v0.6.5-dev.1`。

- 损益科目树、底稿目录和主要 AI 事实只列独立发生额；本期、上期与月份仍保留缺数状态。收入函证的客商交易额缺少独立来源时留空，不能以辅助余额代填。
- 问答按提问选取报表项目及其原值、备抵与明细，保留零额和零变动科目；短追问可沿用近期范围。全局变动摘要不再被当作完整项目数据，范围截取仍明确告知。
- 项目净额等汇总由本地计算，未知发生额不补零；回答应区分数据观察、待核实风险和具体程序，通用会计与审计方法可以直接说明，不把项目证据缺口当作所有问题都无法回答。
- 知识检索在数据预览前完成；实际发送的事实、历史和参考材料与预览一致。离题限制、数字核验、引用检查和提案人工复核继续保留。

测试仅使用合成数据和模拟模型传输，没有调用用户 Key 或发送真实账套。模型的实际回答质量及真实账套业务验收仍需在项目中复核。未知原插件公式和完整附注/报告生成仍未实现。
