# DeepAudit 0.6.5 本地开发版

本轮修正损益展示与审计问答的事实范围，仅做本地开发与打包，不同步远端。

- 损益科目树、底稿目录和主要 AI 事实只列独立发生额；本期、上期与月份仍保留缺数状态。收入函证的客商交易额缺少独立来源时留空，不能以辅助余额代填。
- 问答按提问选取报表项目及其原值、备抵与明细，保留零额和零变动科目；短追问可沿用近期范围。全局变动摘要不再被当作完整项目数据，范围截取仍明确告知。
- 项目净额等汇总由本地计算，未知发生额不补零；回答应区分数据观察、待核实风险和具体程序，通用会计与审计方法可以直接说明，不把项目证据缺口当作所有问题都无法回答。
- 知识检索在数据预览前完成；实际发送的事实、历史和参考材料与预览一致。离题限制、数字核验、引用检查和提案人工复核继续保留。

测试仅使用合成数据和模拟模型传输，没有调用用户 Key 或发送真实账套。模型的实际回答质量及真实账套业务验收仍需在项目中复核。未知原插件公式和完整附注/报告生成仍未实现。

验证记录：相关区域 128 项测试通过（92.102 秒）；最终代码的 37 个测试模块完整回归 **629 项通过（116.450 秒）**。新增 9 项回归覆盖无变动原值与备抵、超限与连续追问、自定义科目、损益发生额口径、收入交易额缺源、科目树、实际预览/发送一致性，以及模拟模型收到完整相关事实后的金额校验。

完整回归命令为 `.venv/Scripts/python.exe -B -m unittest <rg --files tests -g test_*.py 返回的全部模块>`，临时目录位于项目内。日志为 `local-data/codex-review-20261105/pl-chat-targeted.txt` 和 `pl-chat-full.txt`；原始日志不提交。
