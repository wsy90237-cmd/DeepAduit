# Attesta 品牌资源

Attesta 的名称、图标和启动文件名以 `tb_autofill/brand.py` 为唯一来源；换名或换图时先改这里，再跑 `tests/test_brand.py`。

## 图标

图标由项目所有者提供的品牌图裁切而来：橙色圆角方块内是白色连续折线 A。`packaging/attesta.ico` 包含 16、24、32、48、64、128、256 七档尺寸。

| 文件 | 用途 |
| --- | --- |
| `tb_autofill/assets/attesta-32.png` | 对话面板与紧凑位置 |
| `tb_autofill/assets/attesta-48.png` | 侧栏品牌 |
| `tb_autofill/assets/attesta-256.png` | 窗口与任务栏图标 |
| `packaging/attesta.ico` | Windows 可执行文件图标 |

## 颜色

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 画布 | `#FEFAEF` | 品牌图的暖米色背景 |
| 正文 | `#291C13` | 品牌图近黑，不直接用纯黑 |
| 操作橙 | `#B5520D` | 白字对比度 5.0:1、米色底 4.7:1 |
| 悬停橙 | `#97420A` | 按下与悬停 |
| 浅橙 | `#FBE7D3` | 当前导航项、选中底色 |

图标本身使用品牌原图的亮橙 `#EE6C14`。亮橙不做按钮底色：白字对比度只有 3.1:1，不满足正文可读性要求。

## 字体与版式

- 英文品牌字：Georgia；中文标题：宋体；正文：Microsoft YaHei UI；数字：Cascadia Mono。
- 页面只保留「状态、动作、结果」三类信息，不写口号、不使用重复标题。
- 具体页面规则见 [界面规范](界面规范.md)。

## 约束

- 不复制其他产品的标志或界面素材；图标只来自项目所有者提供的品牌图。
- 图标与名称必须成对出现；新增用户可见名称时引用 `APP_NAME`，不要写死字符串。
- 旧启动文件名 `启动DeepAudit.cmd`、`DeepAudit-trial.cmd` 仅作兼容入口，内容已指向 Attesta；新包只携带 Attesta 启动文件。
