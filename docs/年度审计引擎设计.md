# DeepAudit 企业年度财报审计引擎设计

目标是以账套为数据主线，把审计程序、证据、TB、附注、底稿和报告连接起来。当前取数接口只覆盖科目余额；仅凭余额无法替代序时账、凭证、外部证据和项目人员的判断。0.5.0 先完成模型与知识接入、文字辅助复核及全流程页面设计。

## 页面与真实能力

| 页面 | 0.5.0 可使用 | 后续建设 |
| --- | --- | --- |
| 审计驾驶舱 | 主体期间、科目和字段统计、待办数量、接入入口 | 多项目持久化、负责人、进度与版本 |
| 账套与 TB | 一致副本取数、识别匹配、差异复核、人工确认、Excel 另存 | 扩展总账/明细账/序时账、完整调整分录及审定表 |
| 风险与计划 | 设计页面、知识库入口 | 项目承接、准则范围、重要性、风险与认定、计划审批 |
| 程序与证据 | 设计页面、明确证据缺口 | 程序执行、抽样、函证/监盘记录、证据索引与复核 |
| 财务报表附注 | 已有文档文字与知识辅助复核 | 科目映射、比较数据、明细收集、勾稽、模板生成 |
| 审计底稿 | 已有文档文字与知识辅助复核 | 真实程序与证据关联、编制/复核、版本及导出 |
| 报告中心 | 动态准备清单、缺口说明、HTML 清单、已有报告文字复核 | 报告组装、意见判断、复核门槛、签发归档 |
| 财会知识库 | 本地文件、ima 搜索、来源片段、引用编号 | 有效期/适用性标签、资料管理；达到规模后再评估向量检索 |
| 模型与安全 | API、模型发现、对话验证、加密凭证、日志校验 | 团队权限、受控模型网关、独立存证与授权 |

界面中的“设计阶段”“待接模板”是尚未实现的能力。报告清单始终标为未就绪，不会以 TB 匹配成功作为已完成审计的证明。

## 数据与 Agent 分工

1. 取数层只读取经过校验的一致副本，记录主体、期间、账套指纹和单位。扩展账套格式时仍遵守只读，不修复或升级原库。
2. 计算层负责 Decimal 金额、借贷方向、父子层级、期间和勾稽规则。TB 账面、调整与审定口径分开，缺少依据时保留缺口。
3. 知识层提供可追溯文字及来源，不充当项目已经执行的程序或取得的证据。ima 访问权与资料使用权由账号和资料授权决定。
4. Agent 将本地事实、项目范围和所选材料整理成问题与建议。只调用受限检索和结构化对话；不开放 shell、任意数据库写入或自动签发工具。上传前可预览目的服务和资料范围。
5. 复核层由项目人员确认建议与证据。未来生成文件仍须先给出可检查的草稿，保留原模板、公式和人工调整，另存新版本。

## 后续需要保存的关系

先确定模板并落实一个科目闭环，再落地项目存储，避免预建空模块：

| 对象 | 应保存的核心信息 |
| --- | --- |
| 项目 | 主体、报告期间、适用准则、行业、范围、人员职责 |
| 数据快照 | 账套与模板指纹、科目余额/明细版本、单位、读取时间 |
| 风险与程序 | 风险、认定、重要性、程序内容、责任人、状态、执行结果 |
| 证据 | 来源文件哈希、取得时间、索引、关联程序、权限与版本 |
| TB/调整 | 源快照、账面金额、批准的调整、审定金额、比较期间、确认人 |
| 附注/底稿 | 模板版本、TB 版本、字段/证据映射、编制与复核状态 |
| 知识引用 | 提供方、原文标识、片段、取得时间、版本/生效期/适用范围 |
| 报告 | 所用财报和附注版本、结论与差异汇总、复核审批及签发归档记录 |

任何来源版本变化都应使相关结论转为“待重新复核”，不能静默沿用旧意见。项目持久化和多级审批当前未实现；本地日志不等于独立不可篡改存证。

## 建设顺序与验收

1. **接入与辅助复核（本版）**：离线 TB、密钥隔离、知识检索、上传预览、来源引用、现有文档文字复核、报告准备度；实际账号权限需用户在软件验证。
2. **一类底稿和附注闭环**：先确定适用模板及合成样例，以一个科目实施“程序—证据—TB—附注—底稿”全过程。验收标准是金额可回溯、缺失信息显式保留、输入变更后强制重审、输出不改原文件。
3. **扩展数据与审计模块**：按优先科目接明细、凭证和证据管理，再扩展风险、抽样及程序库。每一项能力都须有独立来源和可检查结果。
4. **财报与正式报告闭环**：确认财报、附注及报告模板，落实调整差异、持续经营等项目结论和复核记录；具备审批、签发与归档规则后才开放正式报告出口。
5. **团队部署**：有多人协作和商业授权需求时，将权限、授权签发、必须保密的算法及独立留痕放到受控服务；桌面原生编译只能提高还原成本。

知识库不能替代项目证据、适用准则核对或注册会计师判断。可参考 [广东省注册会计师协会年度财报审计工作提示](https://www.gdicpa.org.cn/gsgg/xhgsgg/content_20205) 中有关程序和证据的官方说明；具体项目仍按其适用准则与业务范围执行。
