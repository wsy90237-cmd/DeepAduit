# TB 父科目路径与同名分项

父科目名称可能同时出现在不同类别中，例如损益科目“财务费用”和“在建工程/财务费用”。按父科目限定来源时，优先使用规范化后与完整父路径吻合的科目；其他类别下的同名叶子不能扩张该父科目的范围。完整路径仍有多个候选时继续待复核，不能据金额、科目编码前缀、行号或列号消除歧义。

明确提供嵌套路径时保留该路径。来源缺失、两个同路径父级、同一父级下多个同名分项仍不自动填列。自动匹配、人工/AI来源校验和写入前校验共用相同规则。此规则只修正取数范围，不判断某笔费用应否资本化，也不新增利息净额或发生额公式。

合成验证位于 `tests/test_parent_paths.py`：包括资本化同名费用排除、明确嵌套路径、缺失/重复父级、重复叶子、共享入口校验、空白/零/反向发生额、利息收入正号与混合发生额、上期审定来源隔离，以及移行、移列、表页改名、分层表头和元/万元的24种组合。执行项目完整单元测试即可复现，不需要真实客户资料。

- 财会〔2006〕3号，文件日期2006-02-15，自2007-01-01起在上市公司施行并鼓励其他企业执行；官网转载日期2008-05-22。[官方通知](https://kjs.mof.gov.cn/zhengcefabu/200805/t20080522_33653.htm)。

以上只支持保持类别与路径边界。样本实际适用的会计制度、后续版本及具体资本化判断需独立项目证据；不因知识检索推定样本执行此制度，不按新准则改写历史金额。科目来源和原TB原填金额均不能替代审定证据。
