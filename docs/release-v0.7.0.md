# Attesta 0.7.0 开发预览（品牌与界面重构）

本轮把产品更名为 **Attesta**，启用项目所有者提供的橙色 A 图标，并按「只保留状态、动作、结果」重做界面。数据读取、匹配、导出与审计口径不变。

- **品牌**：名称、图标路径、可执行文件名与启动脚本集中到 `tb_autofill/brand.py`；窗口、侧栏、报告页脚、底稿提示和导出清单统一使用 `APP_NAME`。
- **配色**：画布取自品牌图的暖米色 `#FEFAEF`，正文用近黑 `#291C13`；操作橙 `#B5520D` 满足白字 5.0:1、米色底 4.7:1，亮橙只保留在图标中。
- **首页**：只显示项目名、期间/账套/模板与三项数字；主按钮文字随状态变化（读取账套 → 选择模板 → 确认 N 项 → 核对差异 → 查看结果）。
- **页面收敛**：删除首页模块入口、底稿流程图、附注与设置页的说明段落、TB 表内的操作提示和常驻日志。设置页保留模型状态、模型设置、日志校验与运行日志。
- **功能未减**：底稿页保留制作、选择待复核底稿和复核底稿文字；报告页保留准备清单与复核；TB 底部保留导出核对表、另存 Excel 与退出。运行日志改为按需打开。
- **尺寸修正**：结果表默认高度改为 7 行，确保 1366×768 与 125% 缩放下底部操作区仍在首屏。

验证：完整回归见提交记录；新增 `tests/test_brand.py` 覆盖名称、图标尺寸、ICO 档位与启动脚本编码，`tests/test_workspace.py` 覆盖首页状态与主操作切换。

限制不变：附注与报告生成未实现，模板外部函数未取得，真实账套仍需业务验收。
