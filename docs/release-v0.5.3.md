# DeepAudit v0.5.3（加固编译版）

本版聚焦两件事：模板识别在真实大模板上的稳定性，以及分发产物的逆向成本。

## 识别与性能

- 扫描边界改由已占用单元格决定。此前按工作表声明区域展开，格式残留会把矩形撑到百万级，单个辅助页即可让识别停滞。
  实测同一份含 40,000 行辅助页的模板：识别耗时 139.5 秒、峰值内存 589 MB，本版为 0.13 秒、2.2 MB，识别结果字段数不变。
- 超大辅助页不再参与解析：识别在临时副本上进行，按工作表 XML 体积与页名判定，原模板与客户文件不被改写。
  若剔除后未确认任何试算平衡表，自动回到原文件识别并提示较慢，避免静默漏识别。
- 修正整页误丢弃：试算平衡表仅因右侧存在过期格式（声明 900 列、实际 20 个单元格）此前会被判为「使用区域过大」整页跳过，
  识别结果为 0 字段；本版正常识别，5 个字段，0.44 秒。
- 迁移契约同步改为按内容判定：占用行超限丢弃整页并提示范围，远处零散格式只收窄范围。

## 分发加固

- 全部业务模块原生编译，分包内不含 `.py`/`.pyc`，常规解包与反编译工具链取不到源码。
- 链接期优化（LTO）、去除断言与文档字符串、单文件压缩载荷、隔离运行模式。
- 说明：加固提高还原成本，不能保证任何人都无法逆向。程序在本机执行，运行时行为始终可被观察。
  未加入反调试与加壳，原因是审计环境普遍部署 EDR，主动对抗容易被判为可疑行为。

## 接口与复核

- 接入 DeepSeek 兼容接口后，可完成「本地识别 → 匹配 → 对话复核 → 改动提案」闭环；
  提案须人工确认，金额始终由本地计算点重算，AI 不直接写数。
- 越界问题（非审计话题）会被拒绝；回答中出现的账套外金额与不存在科目编码会被事实核对层标出。

## 验证

- 单元测试 232 项通过（CI 使用 Python 3.13）。
- 真实样本回归：3 份 2025 年度单体试算平衡表，各 1,012 字段，与既有回放记录一致。
- 真机 Excel 原生迁移试填未重跑：脚本要求冻结源码哈希，本轮修改了识别模块，需重新交叉复核后执行。

## 已知限制

- 单份真实模板仍约 5–6 秒，耗时集中在工作簿全量解析。
- 纯文本型超大页（大段文字进入共享字符串表）不触发体积投影。
- 正式报告生成、全表勾稽与签发仍未实现；仅有科目余额不能完成全部审计程序。
