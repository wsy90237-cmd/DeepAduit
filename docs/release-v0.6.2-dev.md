# DeepAudit 0.6.2 开发预览

- 修复“AI 建议专项表”仍走通用聊天协议、无法解析正文 JSON 的遗漏，统一使用独立的结构化底稿请求。发送前预览包含完整系统要求、问题、事实及目的服务，取消不发送。
- 校验专项表增删数组、可用表名及数量；网络、截断和格式错误明确显示“专项表建议失败”，不再误报为“无需调整”，已有选择保持不变。
- 科目下拉框只显示去重后的报表项目（如“1-150 存货”）；下方按一级科目展开二级明细，列出编码、名称及账面余额。点击下方科目切换当前一级底稿，切换后旧文字、序时账与专项表建议失效。
- 同一报表项目下的多个一级科目分别制作底稿，每册只含当前一级科目及其明细。未匹配报表项目的科目明确提示核对，不能静默套用模板。
- 自动界面测试拦截错误对话框，失败直接记录为测试失败，避免临时目录权限错误打断桌面操作。

继续提供自带 Windows x64 Python 的未编译开发包。正式客户 EXE 仍使用 Nuitka；审定数与调整不由账面金额代填，完整证据勾稽、附注和报告生成仍待实现。
