# DeepAudit 0.6.6 开发预览（界面改版）

本轮只改界面与交互，不动取数、导出和审计口径。视觉方向改为暖白纸面 + 衬线标题 + 单一陶土色强调的克制版式，文案同步精简。

- **设计令牌集中管理**：新增 `tb_autofill/theme.py`，统一颜色、字阶、间距、控件样式与动效；`gui.py`、`workspace.py` 不再各自硬编码色值。
- **版式**：左侧白色索引栏只保留文字导航，选中项用陶土色细线与浅色底标记；页面改为「页头 + 一条说明 + 内容」，去掉重复标题与冗长按键说明。
- **工作台**：项目名用衬线大字，三项指标（已载入科目、待确认事项、现有值差异）以数字为主角；四个模块收成两列列表，悬停高亮、点击进入。
- **账套与 TB**：表单固定单列，避免高分屏缩放后「填列期间」「识别并匹配」被挤出卡片；结果表状态色改为语义软色，行高与表头更易读。
- **底稿页**：主操作只留「制作报表项目底稿」与「选择待复核底稿」，右侧用一行式口径示例替代长段落。
- **可访问性**：正文与次要文字在纸面、白卡上均 ≥ 4.5:1；主按钮白字对比度 5.2:1；动效尊重系统「减少动画」设置，可用 `DEEPAUDIT_REDUCED_MOTION=1` 关闭。
- **预览工具**：`tools/preview_ui.py` 增加 `--shot <png>`，可在进程内截取指定页面，便于设计核对，不接触真实账套。

验证：38 个测试模块、**663 项通过**；新增 `tests/test_theme.py` 覆盖配色对比度、卡片内边距与动效降级。取数、导出与审计口径未变，附注与报告生成仍未实现。
