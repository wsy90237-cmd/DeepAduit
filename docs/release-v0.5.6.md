# DeepAudit v0.5.6

本版把「国内审计助手」接入内置知识库，并让底稿按一级科目起草、可带鼎信诺序时账。金额仍由本地规则计算，AI 只组织文字。

- 新增内置知识 `china-audit`（国内审计助手）：18 篇审计程序指引 + 4 份底稿/询证函模板，本地检索，不联网。
- 底稿科目支持按级次筛选，默认一级科目；该级次无可做底稿的科目时自动退回全部级次并说明，不再出现空白下拉。
- 新增鼎信诺序时账（凭证分录）只读取数：按科目编码前缀取分录，借贷合计与科目余额表发生额自动勾稽，不一致直接写明。
- 底稿事实新增序时账摘要：笔数、月度分布、按借贷方向拆分的对方科目、金额最大与期末抽样凭证；导出的 HTML 顶部显示序时账笔数与勾稽结论。
- 底稿检索优先使用审计 skill，命中不到才回落到全库；模型自造的 `[Kn]` 编号在导出前删除并记入告警。
- 修复金额核对把序时账金额与科目本级、下级金额误报为编造的问题。

验证：本机 357 项合成测试通过；真实账套（22 南平市延平区太平国有试验林场 / 2026-09 / 102 银行存款）读取 962 个科目、序时账 159 笔，借贷合计与科目余额表一致；营业收入 501 序时账 9 笔中识别 7 笔收入确认（2,524,322.00）与 2 笔结转，收入确认合计与科目余额表一致。

只下载本页的 `DeepAudit.exe`、`SHA256SUMS.txt`、`INSTALL.txt`、`BUILDINFO.json`。EXE 的 SHA-256 必须与本页清单一致。本版由 windows-latest 原生编译（MSVC，17 个业务模块全部原生），构建后复验自检通过。未提供代码签名，未知本机策略或未知模板兼容性仍需实际验证。

底稿草稿仍为辅助产出：期初审定数、审计调整、审定数与结论需人工判断，附注与报告不自动出具。
