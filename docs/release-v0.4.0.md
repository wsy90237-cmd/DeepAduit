# DeepAudit v0.4.0

原 ZSZH TB 自动填写系统更名为 DeepAudit，改为项目总览、TB、附注、底稿和安全与设置的审计工作台。

- 修复切换主体、期间、模板或单位后沿用旧结果的问题，导出与日志采用相同上下文快照。
- 修复多层表头对审定数与调整分录的保护，并阻止本月发生额被累计额代替。
- 修复后台异常导致任务队列停转，扩展输出比对至前后有效单元格并集。
- 日志加入文件锁和加密末尾检查点，旧日志明确显示校验范围。
- 正式包改用 Nuitka 原生编译并检查全部业务模块；密钥继续使用 Windows DPAPI。

附注编制与底稿生成尚未实现，本版提供其规划入口。原生编译提高逆向成本，不能保证无法还原；未配置代码签名证书。

仅使用 `DeepAudit.exe`、`SHA256SUMS.txt`、`INSTALL.txt` 和 `BUILDINFO.json`。旧版本机设置保持兼容。
