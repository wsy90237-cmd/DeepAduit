# DeepAudit v0.5.4（内置知识库 + 工作台重排）

本版把两套会计知识库内置进程序，并重做工作台布局，解决小屏上内容被裁切的问题。

## 内置知识库

- 随程序分发两套知识：陈版主会计判断（2,334 条）与 IPO 财务核查（338 条），合计 2,672 条、1.49 MiB。
- 问答与复核**先在本地检索**，命中条目以 `K1`、`K2`… 注入上下文；未命中时明确回复“无匹配条目”，不臆造准则条号。
- 检索为纯本地确定性算法（2-gram + 词权重 + 轻量 IDF），同输入同输出，不联网。
- 长句按分句分别检索再合并，避免整句覆盖率把核心术语稀释成零命中。
- 「财会知识库」页面与 ima 外链配置已移除；知识库不再以列表形式展示，也不需要手工选用条目。

## 工作台布局

- 窗口尺寸按可用桌面计算（屏幕高减 130px），最小 1000×620；两列布局下最小宽度 1180。
- 宽屏时「① 数据源」与「② 模板与期间」并排，窄屏自动堆叠；表单区独立滚动，纵向余量留给结果表。
- 实测 1446×734：表单区 176px、结果表 226px、操作区与日志完整在可视区内；侧栏品牌与表头状态不再被裁切。
- 结果表列宽按可用宽度收紧，横向滚动条常驻。

## 识别引擎（沿用并收尾）

- 年初未分配利润只取明确对应科目的年初账面余额，54 份回放样本全部改为 `opening_balance` 口径。
- 模板声明截止日期与账套期间在匹配前、写入前核对。
- 索引编码不得覆盖科目文字；普通模板的 AI 建议需通过同一套选源校验。
- 迁移试填 3 个 case 全部 `export_verified`，差额保留不美化。

## 验证数字

- 单元测试 279 项通过。
- 回放 54 份样本、54,649 个字段；期末 matched 4,678（与原填数一致 984、差额 67），期初 protected 22,979。
- 迁移试填：case1 hidden 393 / written 101；case2 394 / 79；case3 393 / 102。

## 已知限制

- 差额与待复核项一律保留，需人工判断；未在真实样本上验证 AI 选源与索引编码冲突两类修复（仅合成测试）。
- 检索引擎基于字面匹配，同义词与长距离语义仍可能漏检。
- 正式报告生成、全表勾稽与签发未实现。
