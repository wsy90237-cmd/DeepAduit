# DeepAudit v0.5.5

本版修复 AI 来源复核摘要、评测统计和发布校验问题。上期审定、公式保护、歧义复核及写入前来源校验继续生效。

- 父子摘要只核对直接子级，余额统一方向；缺失信息返回未知，避免重复汇总和缺失当零。
- 损益按发生额度量进入复核，年初利润按年初余额处理；重复或结构错误的 AI 返回不采纳。
- 评测默认先保存请求预览，明确批准相同范围与服务后才能发送；原填数隐藏，原填空白与误填分开记录。
- 修复 QA 快照字段丢失、过期缓存、同名主体任取、公式重复计数、单位容限及跨模板范围比较。
- 纳入完整父级路径和“其他收益”总额必须使用一级来源的匹配修复。
- 发布要求全部17个业务模块原生编译，并绑定构建前后相同的干净源码版本。

验证：本机330项完整合成测试及源码离线自检通过；正式发布还需云端原生编译、自检和上传后下载校验。[代码审查记录](review-v0.5.5.md)。本轮未重新进行客户账套试填或真实外部模型联调。
