# 独立账表试算预览

开发实验，从已规范化的两份 CSV 本地生成 TB 匹配预览，不读鼎信诺账套，不请求模型。正式桌面流程暂不改变。不应将试验输出视为已审定的 TB。

在仓库根目录运行 `python -m tools.preview_external_tb 余额表.csv 序时账.csv 模板.xlsx 预览.csv`。预览用新文件名；已有文件不会覆盖。检查匹配结果及期间警告后，可换一个预览名并追加 `--output TB草稿.xlsx`，由 Windows Microsoft Excel 另存并重算。草稿只写已匹配的空白账面字段，保留原有单元格、公式和调整。未匹配与已存在值的差异留在预览中。

两份 UTF-8 CSV 的每行均须包含 `主体,账套,截止月,币种`，截止月示例 `2026-06`，仅支持 `CNY`。列可换序；目前不自动推断异名列或金额方向。

- **科目余额表**其余列：`科目编码,父级编码,科目名称,科目方向,科目类别,年初余额,本年借方发生额,本年贷方发生额,期末余额`。包括全账套，不可只给银行项目。科目编码保持文本和前导零；父级先于子级，一级父级留空。科目方向必须是科目正常方向 `借` 或 `贷`，科目类别填 `资产负债`（所有非损益科目）或 `损益`。余额统一借正贷负，发生额列不混入本月额或审计调整。零显式写 `0`。
- **序时账**其余列：`凭证日期,凭证号,分录号,科目编码,借方金额,贷方金额`。覆盖年初至截止月末；凭证号应包含字别等区分信息，同日同凭证号各分录号唯一。一行只允许一边有非零金额，红字保留原方向的负数。分录仅可指向末级科目。

程序检查母子科目勾稽、逐张凭证平衡和逐末级的借贷发生额，再沿用 TB 模板规则匹配。预览保存两份原始 CSV 的 SHA-256。两份导出若同时复制了相同错误，勾稽不能发现该错账。暂不导入审计调整或上期审定数，也不把年累计借贷合计冒充损益本期发生额；不验证真实厂商导出布局和整册底稿链路。

合成回归：`python -B -m unittest discover -s tests -p test_external_tb.py`。
