ZSZH TB 自动填写系统  v0.3.0
================================

双击「ZSZH-TB-Autofill.exe」即可运行，无需安装 Python。

运行要求
--------
1. Windows 10 / 11（64 位）
2. 已安装 Microsoft Excel（另存与重算需要；WPS 未验证）
3. 已安装鼎信诺（科目余额库为 MyISAM 格式）

首次使用
--------
1. 打开软件会自动探测鼎信诺安装目录；未探测到请点「选择…」指定含 bin\mysqld.exe 的目录
2. 「扫描项目」→ 选项目 → 选主体单位、年度、截止月份 →「读取科目余额」
3. 选模板文件 → 选「仅期初 / 仅期末 / 期初+期末」→「识别并匹配」
   （换模板后若已读取科目余额，会自动重新识别）
4. 核对结果表中的状态、应填值、现有值、差额、来源科目
5. 勾选要写入的字段 →「另存为 Excel…」→ 生成新文件（原模板不改动）
6. 需要留痕时点「导出复核报告（CSV）」

AI 复核（可选）
--------------
在「AI 设置」中填入自己的 DeepSeek API Key，Key 以 Windows DPAPI 加密保存在本机，
不写入程序目录。不填 Key 也能完整使用，只是没有 AI 建议。
AI 只能建议「用哪个科目」，金额一律由本地规则计算。

文件校验
--------
在解压目录打开命令提示符执行：

    certutil -hashfile "ZSZH-TB-Autofill.exe" SHA256

结果应与 SHA256SUMS.txt 中记录一致。

重要提醒
--------
- 原模板不会被修改，写入只发生在另存的新文件
- 已有数值的单元格默认不勾选，覆盖需逐项确认
- 公式单元格受保护，不会被写入
- 无法确定的项目会标为「待确认 / 未匹配 / 缺少依据」，不会自动猜测或并入「其他」
