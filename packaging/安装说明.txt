DeepAudit  v{VERSION}
================================

双击 DeepAudit.exe 运行，无需安装 Python。
需要 Windows 10/11 x64；Excel 另存需要本机 Microsoft Excel；取数需要鼎信诺 MyISAM 科目余额库。

1. 进入「账套与 TB」，选择安装目录、项目、主体、年度和截止月份。
2. 读取科目余额后导入模板，确认填列期间与金额单位，点击「识别并匹配」。
3. 核对来源、应填值与差额；已有值默认保留，覆盖需逐项确认。
4. 另存 Excel 或导出复核报告。原模板不改动。
5. 切换主体、期间、模板或单位后需要重新取数或识别。

AI 可选：在「AI 设置」填模型 API 地址、Key 和模型，先验证凭证，按需测试对话。
默认 DeepSeek；兼容接口须支持 /models 和 JSON Chat Completions。换地址必须重新输入对应 Key。
在「财会知识库」可导入有权使用的 TXT、MD、DOCX、文字 PDF，或配置 ima Client ID 与 API Key。
ima 官方接入说明：https://ima.qq.com/agent-interface；关注的库是否可读以实际 API 权限为准。
检索正文后选用依据，点击 Agent 辅助复核；请求会先预览目的服务和发送内容。
附注、底稿与现有报告支持文字辅助复核；完整生成、全表勾稽及签发尚未实现。
「报告中心」只能导出准备清单，不是正式审计报告。仅有科目余额不能完成全部审计程序。

安全与校验
--------
正式包使用原生编译，提高代码还原成本，但不能保证任何人都无法逆向。
当前未配置数字签名；请通过可信来源取得发布包，并核对 SHA256SUMS.txt。
凭证用 Windows DPAPI 加密保存到 %LOCALAPPDATA%\ZSZH-TB\connections.json。
新文件不存在时兼容读取旧 settings.json；保存不会覆盖旧文件。不要在聊天中发送 Key。
日志保留原目录；本地知识文字缓存 knowledge.sqlite3 未加密，需保护本机账户及磁盘访问权限。
本机日志有哈希链与末尾检查点；旧日志仅能验证链内一致性。
同时回滚本机日志和检查点无法由单机软件可靠发现，独立存证需服务器支持。
本机日志和复核输出可能含财务信息，请妥善保管。

客户分发只需 EXE、SHA256SUMS.txt、INSTALL.txt 和 BUILDINFO.json。
不要把源码、开发包、构建目录、真实账套、Key 或日志随软件发给其他人。
