# 质量核对工具（本机运行，不上传任何客户数据）

用训练目录里已填好的 TB 作为答案，逐格核对本地填列结果，并把每个数字回溯到来源科目。

| 脚本 | 用途 |
|---|---|
| `per_file_check.py <目录>` | 逐家核对：读鼎信诺账套（按项目分组、批量读库、复合键缓存）→ 识别模板 → 逐格对答案 → 输出 JSON/Markdown 清单 |
| `compare_answers.py` | 用三份标准答案做逐格比对，区分 一致/差额/漏填/误填/公式保护 |
| `eval_ai_review.py <序号>` | 只把疑点与候选交给模型，AI 定来源、本地算金额，最后对答案，衡量 AI 复核的实际命中 |
| `crosstest.py` | 同一账套 × 多套模板交叉校验：可重算性、写入一致性、跨模板冲突 |

约定：
- 答案列大量是公式，必须用 `data_only=True` 取缓存值比对，否则会把公式当"非数值"。
- 金额为 0 且目标格为空白时不写入（答案语料里空白通常表示无此项）。
- 期初"上期审定数"必须有审定来源，账面期初不能替代。
