# DeepAudit 审计工作台

DeepAudit 面向企业年度财务报表审计。从鼎信诺科目余额的只读副本取数，按用户模板识别、匹配、复核和另存 TB；接入模型和财会知识，辅助复核 TB、附注、底稿及现有报告。金额由本地规则计算，AI 只提供建议。0.6.4 当前为开发版本，支持按报表项目整册制作底稿草稿及 Excel 导出（含备抵与客商辅助明细、损益 1—12 月发生额）；附注、报告生成与完整证据勾稽仍待实现。

## 工作空间

0.5.1 使用原创蓝色像素鲸鱼图标及白底蓝色界面，EXE、窗口和导航品牌统一。资源与生成说明见 [品牌资源](docs/品牌资源.md)。

- **工作台**：查看当前主体、期间、模板和 TB 处理状态，维护编制人与复核人的本机设置，进入常用工作。
- **账套与 TB**：读取账套、导入模板、确认来源、复核差额、另存 Excel、导出 CSV。
- **审计底稿**：点击“制作报表项目底稿”，下拉框只显示去重的报表项目（如“1-150 存货”），下方展开该报表项目在账套中归集到的全部科目及明细，显示编码、名称及期末账面余额。**一册即该报表项目的整册**：货币资金含库存现金、银行存款、其他货币资金；固定资产含原值、累计折旧及对应减值准备；无形资产含原价、累计摊销及减值准备；贷方备抵按真实方向参与净额。点击下方科目只用于查看，不会缩小出册范围。往来明细按账套中实际选中的客商核算维度列示名称与余额，不叠加项目、部门等维度；损益明细表列示 1—12 月发生额及本期、上期发生额，只用独立发生额来源。未配置模型也可导出本地 Excel 草稿；AI 填写文字或建议专项表前，先预览实际发送的问题、数据、知识片段及目的服务，取消则不发送。专项表建议与底稿文字均使用独立的结构化请求，格式或网络失败明确提示，不再显示为“无需调整”。审定数与未知调整留空待复核。

  “AI 分析变动与审计说明”会按账套事实生成自然段说明，并填写分析程序表的解释栏；金额与变动仍由本地计算。账面/未审核对与审定核对分开列示，未知不按零处理。截止性表自动筛选可疑分录并写明理由，业务归属及是否跨期由项目组核实。实现和验证范围见[底稿分析与截止性说明](docs/paper-analysis-2026-11-04.md)。
- **财务报表附注**：导入现有文档，按已确认的主体、期间、TB 版本和知识依据进行文字辅助复核。来源变化后重新复核；附注、报告生成与完整证据勾稽仍待实现。
- **报告中心**：动态准备清单、缺口说明、HTML 清单导出及现有报告文字复核；不自动出具审计意见。
- **财会知识库**：本地资料导入检索、ima 只读搜索、知识引用和 Agent 复核；内置「陈版主会计判断」「IPO 财务核查」「国内审计助手」三个离线 skill。
- **模型与安全**：模型 API 配置、鉴权与对话能力验证、本机日志校验、发布保护范围。

## 模型与知识库接入

在应用「AI 设置」中输入自己的 Key，验证凭证并获取模型，再按需验证对话能力。默认 DeepSeek，也支持提供 `/models` 与 JSON Chat Completions 的 HTTPS 兼容接口。切换 API 地址必须重新输入对应服务的 Key。对话能力测试会产生少量 token 用量，点击前有提示。

ima 需要独立的 Client ID 和 API Key，在 [ima 官方开放接口页](https://ima.qq.com/agent-interface) 自行配置，再到「财会知识库 → 配置 ima 连接」加密保存。搜索库名或填写库 ID 后检索正文；“已关注”不代表接口必然有读取权限。无法取得正文时不会把标题冒充内容，不能访问的库也不会自动导出或绕过授权。

暂时没有 ima 接口权限时，可导入自己有权使用的 TXT、MD、DOCX、文字 PDF。本地为关键词检索，不提供 OCR 或向量检索。选用 1–5 个正文片段后，Agent 请求先显示目的服务、模型、问题、历史和资料范围；确认后才发送。引用编号缺失或不存在时，提示并丢弃改动提案。引用编号校验不能证明原文适用性或模型结论正确。

详细步骤见 [模型与知识库接入](docs/模型与知识库接入.md)，全流程设计及阶段范围见 [年度审计引擎设计](docs/年度审计引擎设计.md)。

## 数据保护

识别包含“试算平衡表(期初)”或“试算平衡表(期末)”的工作簿时，只识别期初表的“上期审定数”和期末表的“期末未审数”。列位置可移动，按实际表头识别；现金流、调整分录、客户报出数和审定结果列不进入自动填列。合并及合并抵消底稿跳过单体账套自动填列。其他模板仍使用通用表头识别。

上期审定数需要独立的审定来源，当前鼎信诺账面来源不能直接填入。财务费用利息收入及损益字段的正负号按模板明确的填列说明转换；未确认融资费用按借方方向列示，冲回保留反向符号。利息收入同时存在借贷方正发生额而无法区分入账与结转方式时，留待复核。坏账准备分项按准备科目下的对应往来类别匹配，不使用往来本金。

标准TB按资产、负债及权益区段识别列示方向，“减”项按相反方向列示，未确认融资费用及融资收益分别按借方及贷方列示。资产负债表不使用损益科目下的同名明细；例如公允价值变动损益下的“投资性房地产”不能作为投资性房地产资产余额来源。人工或AI选源也受同一校验约束。

现金、银行存款总额字段按科目名称、货币资金上下文及层级识别，使用唯一对应的一级总科目；同名下属账户不与总科目重复相加，也不单独替代总额。缺少总科目或存在多个总科目时保留复核。

模板另列投资性房地产公允价值变动时，投资性房地产输入行按成本分项匹配，公允价值变动单独列示；不使用已含估值变动的总余额代替成本分项。

应收账款、其他应收款等坏账准备分项按完整科目名称及账套层级匹配：只在资产性质的坏账准备范围内，将明确对应应收类别的“坏账损失”明细识别为该项准备；不将混合坏账准备总额或应收本金直接代入单项准备。

期末表项目名称使用工作簿内直接单元格引用时，可读取被引用的文字以识别字段；不执行任意公式，不用外部链接猜测项目名称，金额公式仍受保护。

应交税费分项仅在应交税费或应交税金科目路径内识别已确认的税种名称及简称；多个候选或父科目时留待复核，不使用其他科目下的同名费用。

教育费附加、地方教育费附加等税费按明确税种分别识别；支持直接税种及“其他应交税费/其他应缴税费”汇总下的税种，不穿过其他具体税种或工程分类。层级、路径叶名和科目名称必须一致。薪酬福利费仅取应付职工薪酬下直接福利类别，不以独立应付福利费、费用或劳务派遣子项替代。

防洪费字段出现水利基金等相关来源时，先提示范围歧义，不自动将两者视为别名或选取同名零余额。

单体TB可按明确页名或表内标题识别，支持目标表头拆为“上期＋审定数”“期末＋未审数”；改名不扩大到辅助表或调整列。标题冲突、重复目标列及合并/抵消范围保留复核。持续学习、模板变化验证和财会知识版本要求见[单体学习与模板迁移验证](docs/单体学习与模板迁移验证.md)。

金额单位随位置变化继续识别。“自动”模式遇到单位冲突或无法解析的明确单位公式时停止，请核对后明确选择输出单位；手动选择元、万元等有效单位时，按所选单位换算，仍核对模板截止日期与账套期间。扫描范围按实际占用单元格限定，超大辅助页不进入解析，未确认TB页时才回到原文件并提示解析较慢。

期末TB在科目表头上方明确声明截止日期或年初累计期间时，预览与写入前均核对账套年月；日期冲突、非月末或不支持的期间格式停止识别。未声明日期时提示人工核对，不从文件名猜测期间。

期末利润分配区段中明确的“年初未分配利润”，仅从唯一的独立未分配利润科目或利润分配下直接未分配利润明细取年初账面余额，按贷方方向列示并保留亏损符号。缺年初值、路径不符或存在多个候选时不填；该规则不提供期初表所需的上期审定证据。

投资性房地产成本分项与整体或其他计量一级根并存时，先确认完整口径，不自动只取一类成本分项。写入前重新核对自动结果的候选唯一性与范围；来源已变为歧义的旧自动结果不能继续写入，明确人工复核单独保留。

“应交税费-增值税”等汇总字段需要先确认应交、未交、预交等明细的取数范围，不能以单个同名零余额代替整个税种。

存货中的原材料、库存商品等明确总额字段，取对应唯一一级总科目，不重复叠加同名明细；待摊费用总额不使用开发成本下的同名明细。真实上下级重复认领仍留待复核。

累计折旧、累计摊销、使用权资产累计折旧及已支持的固定资产、无形资产、在建工程、合同资产和债权投资减值准备，按资产类别识别独立备抵科目，不因模板排在资产项目下就从资产原值取数。

短期、长期借款的本金和应计利息只匹配明确对应的分项；未拆分总额、利息调整及一年内到期部分不直接相互替代。

标准TB的自动、人工、AI选源及写入前复核使用同一科目文字和路径校验；索引编码不绕过语义，AI不自动决定歧义来源。通用模板的显式人工归集保持原有规则。

Excel导出以只读方式打开原模板，再原生另存副本，以保留相对外链的来源位置。保护校验按实际外链目标和公式引用核对编号重排；真实目标或公式改变，以及无法核对的链接类型仍拒绝导出。

- 复制前持有源文件只读锁，数据库引擎仅打开经过校验的临时副本；原数据库不写入、不修复、不升级。
- 主体、年度、月份、模板、填列期间或单位改变时，旧匹配与 AI 提案失效。后台旧响应不能重新激活旧结果。
- 鼎信诺底稿中的单位编号 D 与账套编号 N 同时绑定取数；同单位、同年度不同账套版本不混合。缺少唯一账套编号时停止取数。
- 写入前核对完整账套指纹与来源成员；实际导出和留痕使用同一份不可混用的任务快照。
- 多层合并表头合并判断口径，保护审定数、调整列、公式和未选期间。
- 当前来源提供年初累计发生额；本月发生额缺少单月依据时报告缺少依据，不用累计额代替。
- 科目缺少中间月份时，不把部分月份之和当作完整累计发生额。损益属性按一级科目确定，开发成本、制造费用等资本化科目的支出明细不作为期间损益。
- 默认只补空，已有值需确认覆盖。Excel 重算后按前后有效单元格并集校验。
- 模型与 ima 凭证分别用 Windows DPAPI 加密，存入 `%LOCALAPPDATA%\ZSZH-TB\connections.json`。新文件不存在时只读兼容旧 `settings.json`，保存不会更改旧版文件，避免旧版误用新服务 Key。
- 知识原文缓存在同目录的 `knowledge.sqlite3`，未加密；本机账户和磁盘访问权限仍需妥善保护。待复核文档只提取文字放入本次内存上下文，不自动加入知识库。
- 新日志有哈希链、文件锁及 DPAPI 末尾检查点，可发现仍有检查点时的尾部截断。旧日志没有检查点时只报告链内校验。不能抵御同一账户回滚全部日志与检查点。

## 运行与测试

需要 Windows 10/11 x64、Python 3.12+；推荐 3.13。Excel 另存依赖已安装的 Microsoft Excel 与 pywin32，WPS 未验证。

本机源码试用：双击项目根目录的 `启动DeepAudit.cmd`，诊断入口为 `DeepAudit-trial.cmd`，使用当前源码与 `.venv` 的依赖。启动入口使用 ASCII 和 CRLF，避免 Windows 命令解释器误读；失败会提示临时日志位置。首次安装依赖仍按下方命令操作。

无需编译的开发包：源码提交后执行 `.venv\Scripts\python -B tools/build_dev.py`（可加 `--template-library <本地模板库>`、`--skip-templates`）。输出到 `dist/DeepAudit-<版本>-dev/`，包含可读源码、自带 Python、运行依赖、离线自检结果及 ZIP 校验值；同时把 `local-data/dxn-library-<日期>` 下的空白模板原件按标准目录带入包内 `templates/`，逐个文件比对 `ORIGINALS.sha256` 后汇总为 `templates/TEMPLATES.sha256`，`BUILDINFO.json` 记录清单哈希，使模板原件可复核、不依赖原软件安装路径。解压后双击 `启动DeepAudit.cmd`，无需本机 Python 或 `.venv`；不包含账套、客户底稿、项目数据、API Key 或本机配置。此包用于内部开发，发布为明确标注的开发预览版本，正式客户 EXE 仍采用下述原生编译流程。

正式程序从 [GitHub Releases](https://github.com/wsy90237-cmd/DeepAduit/releases/latest) 下载，核对 `SHA256SUMS.txt` 后运行 `DeepAudit.exe`。本地离线副本统一保存在 `dist/DeepAudit-<版本>/`，只保留最新一版；源码试用入口不写固定版本号。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python launch.py
.venv\Scripts\python -m unittest discover -s tests -v
```

开发预览使用隔离设置和合成数据：`python tools/preview_ui.py`。安装后的命令为 `deepaudit`，保留旧命令名兼容已有脚本。

## 编译客户发布包

正式发布改用 Nuitka 原生编译，不再提供直接分发业务 Python 字节码的 PyInstaller 配置。

```powershell
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python tools/build_release.py --compiler msvc --jobs 2
```

MSVC 需 Visual Studio 2022+ C++ 构建工具；本机没有 MSVC 可使用 `--compiler zig`，Nuitka 会下载其支持的编译器。源码保留开发能力，编译包用 isolated 模式，减少外部 Python 路径注入；这不等于无法逆向。

只分发以下文件：`dist/DeepAudit.exe`、`SHA256SUMS.txt`、`INSTALL.txt`、`BUILDINFO.json`。不要分发开发包、源代码、C 代码、编译报告、构建目录、真实数据或日志。

构建脚本运行合成金额、DPAPI、日志截断、表头保护、本地知识、PDF 依赖和报告准备度自检，且要求指定的全部 25 个业务模块均为原生编译。源码未提交或构建期间源码发生变化时拒绝生成发布清单。版本只维护在 `tb_autofill/__init__.py`；标签与版本不符时拒绝构建。

GitHub Actions 先测试、MSVC 编译、自检并保存运行产物。确认构建成功后，将构建运行编号、源码提交及 EXE 的 SHA-256 写入 `packaging/publish.json`；发布流程再次自检、上传草稿并下载校验，再公开 GitHub Release。源码仓库目前公开，原生编译不提供源码保密保证。未配置代码签名证书，不能声称已签名。

更多说明见 [安全与发布](docs/安全与发布.md)、[工作空间与扩展规划](docs/工作空间与扩展规划.md)。历史实际账套/API 联调记录保留在 `docs/联调记录.md`，合成测试不能代替真实联调。
