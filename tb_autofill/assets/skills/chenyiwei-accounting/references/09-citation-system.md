# 引用体系速查

## 一、引用层级（由高到低）

写依据时按此顺序找，找到足够支撑即停，不必罗列全部：

1. **企业会计准则条文** + 应用指南
2. **企业会计准则解释**（第 14—17 号）
3. **监管规则适用指引——会计类第 1/2/3/4 号**（证监会）
4. **财政部会计司**：企业会计准则实施问答、PPP 项目合同社会资本方会计处理应用案例
5. **证监会会计监管报告 / 会计监管工作通讯 / 上市公司执行企业会计准则监管问题解答**
6. **年报通知**（财会〔20XX〕32 号类，明确当年监管重点）
7. **事务所研究文献**：《中审众环研究 2020》（原《瑞华研究》）按问题编号引用
8. **审计准则及应用指南、问题解答**
9. 交易所审核动态、《首发业务若干问题解答》

第 7 层是陈版主最常引用的内部技术资料，引用时写「《中审众环研究 2020》之『问题 X-X-XX（问题标题）』」，只写编号不写标题会降低可核查性。

## 六、引用纪律

1. **不虚构条号与文号**。记不清具体条号时，只写准则名称 + 条款主题（如「《企业会计准则第 14 号》关于可变对价限制条件的规定」）。本文件第四节列出的文号方可直接引用；列表之外的财会、财税、国资文号，除非能确认其存在与内容，一律不写编号，改为描述文件主题（如「当年年报通知」「资产损失税前扣除管理办法」）。宁可少写一个编号，不可编造。
2. **区分强制性与参考性**。准则、解释、监管指引是强制性依据；研究文献、审核动态是参考性依据，写「可参考」而非「依据」。
3. **注意时效**。援引文件时确认是否已被修订或废止（如新冠租金减让规定、原租赁准则下的售后回租条款）。
4. **区分会计与税务依据**。税会差异的结论应明确「会计按准则处理，税务按税法调整」，不混用。
5. **先例不等于依据**。引用过往答疑案例时，须核对其事实基础与新问题是否一致；事实不同只能作类比，并注明差异点。
