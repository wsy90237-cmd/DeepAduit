# 筹资与投资循环审计

覆盖银行借款、应付债券、长期股权投资、金融资产、实收资本等科目。

## 审计目标

### 筹资
- **完整性**：所有借款、担保、承诺均已披露
- **存在/发生**：借款真实存在
- **准确性**：利息费用、资本化处理准确
- **列报**：借款分类、受限条款披露充分

### 投资
- **存在**：投资真实存在
- **计价**：长期股权投资核算方法正确、金融资产公允价值可靠
- **减值**：减值准备充分
- **列报**：投资性质、受限情况披露

## 关键程序

### 1. 银行借款

- 获取借款合同、授信协议
- 函证银行借款余额、利率、期限、担保
- 检查借款入账和还款记录
- 复核利息费用计算
- 检查借款费用资本化是否符合条件
- 关注借款合同中的限制性条款

### 2. 应付债券

- 检查债券发行文件
- 复核利息、溢折价摊销
- 检查还本付息记录

### 3. 长期股权投资

- 检查投资协议、章程、出资证明
- 判断核算方法（成本法/权益法）
- 权益法下检查被投资单位财务报表
- 检查减值迹象和减值测试
- 关注投资处置损益

### 4. 金融资产

- 分类检查（以摊余成本计量、FVOCI、FVTPL）
- 检查公允价值确定依据
- 检查减值准备（预期信用损失）

### 5. 实收资本/股本

- 检查公司章程、验资报告
- 检查工商变更登记
- 检查股东出资方式及到位情况
- 关注股权质押、冻结

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 借款余额大但账面现金多 | 资金受限、存单质押 |
| 利息费用与借款余额不匹配 | 体外借款、利息资本化不当 |
| 长期股权投资减值测试激进 | 商誉/投资减值准备不足 |
| 金融资产分类随意 | 利润调节 |
| 股东频繁变更 | 股权代持、控制权不稳定 |
