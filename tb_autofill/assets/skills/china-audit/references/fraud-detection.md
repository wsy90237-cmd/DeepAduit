# 舞弊识别与应对

依据《中国注册会计师审计准则第 1141 号——财务报表审计中与舞弊相关的责任》执行。

## 舞弊三角理论

| 要素 | 表现 |
|------|------|
| 压力/动机 | 业绩对赌、融资压力、IPO、保壳、管理层薪酬与业绩挂钩 |
| 机会 | 内控薄弱、管理层凌驾、一人多岗、董事会监督失效 |
| 态度/合理化 | 管理层对审计态度恶劣、找理由解释异常、不重视合规 |

## 常见舞弊类型

### 收入舞弊
- 虚构销售（空转、走单）
- 提前确认收入
- 总额法虚增收入
- 通过关联方虚假销售

### 成本费用舞弊
- 少计成本、推迟结转
- 虚构采购、套取资金
- 资本化应费用化支出
- 利用费用跨期调节利润

### 资产舞弊
- 虚构资产（存货、固定资产）
- 资产减值准备计提不足
- 通过对外投资转移资金

### 现金流舞弊
- 期末突击回款
- 利用票据贴现美化现金流
- 隐瞒受限资金

## 识别程序

### 1. 分析程序
- 收入/成本/毛利率异常波动
- 收入与现金流严重背离
- 收入与税金、能耗、物流不匹配
- 季度收入分布异常（尤其 Q4 突击）

### 2. 交易真实性测试
- 大额/异常交易穿透核查
- 检查交易对手的工商背景
- 检查合同、物流、资金流、发票的一致性
- 检查是否有真实的商业实质

### 3. 访谈与询问
- 向不同层级人员询问
- 关注回答是否一致
- 询问是否存在业绩压力、管理层干预

### 4. 凌驾控制测试
- 检查期末大额调整分录
- 检查异常 journal entry
- 检查管理层 override 审批的痕迹

## 异常信号清单

| 领域 | 信号 |
|------|------|
| 收入 | 毛利率远高于行业、客户结构突变、期末大额收入、退货率高 |
| 采购 | 供应商集中度高、采购价格异常、付款对象与供应商不一致 |
| 资金 | 体外账户、个人卡收款、关联方资金拆借频繁、受限资金未披露 |
| 资产 | 存货长期不盘点、固定资产闲置率高、商誉减值测试激进 |
| 人员 | 财务人员频繁变动、关键岗位长期空缺、管理层抵制审计 |

## 应对程序

当识别舞弊风险时：
1. 评估风险性质和程度
2. 调整审计程序的性质、时间和范围
3. 增加不可预见性程序
4. 实施更详细的测试
5. 考虑是否需要专家协助
6. 与治理层沟通
