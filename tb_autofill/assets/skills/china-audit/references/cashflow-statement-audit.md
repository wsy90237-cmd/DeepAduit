# 现金流量表审计

依据《企业会计准则第 31 号——现金流量表》执行。

## 现金流量分类

### 经营活动
- 销售商品、提供劳务收到的现金
- 购买商品、接受劳务支付的现金
- 支付给职工以及为职工支付的现金
- 支付的各项税费
- 收到/支付的其他与经营活动有关的现金

### 投资活动
- 购建/处置固定资产、无形资产和其他长期资产
- 取得/收回投资收到的现金
- 取得投资收益收到的现金

### 筹资活动
- 吸收投资收到的现金
- 取得借款收到的现金
- 偿还债务支付的现金
- 分配股利、利润或偿付利息支付的现金

## 审计目标

- **完整性**：所有现金流量均已记录
- **准确性**：金额计算准确
- **分类**：现金流分类正确
- **勾稽**：现金流量表与资产负债表、利润表勾稽一致

## 关键程序

### 1. 直接法编制检查

从现金日记账出发，按交易性质分类汇总。重点关注：
- 大额异常现金流
- 现金流与业务的匹配性
- 受限资金是否从现金及现金等价物中剔除

### 2. 间接法编制检查

从净利润调整到经营活动现金流量净额：

```
净利润
+ 资产减值准备
+ 固定资产折旧、油气资产折耗、生产性生物资产折旧
+ 无形资产摊销
+ 长期待摊费用摊销
+ 处置固定资产、无形资产和其他长期资产的损失
+ 固定资产报废损失
+ 公允价值变动损失
+ 财务费用
+ 投资损失
+ 递延所得税资产减少
+ 递延所得税负债增加
+ 存货的减少
+ 经营性应收项目的减少
+ 经营性应付项目的增加
+ 其他
= 经营活动产生的现金流量净额
```

### 3. 关键勾稽关系

- 销售商品收到现金 ≈ 营业收入 + 销项税 + 应收减少 - 预收减少
- 购买商品支付现金 ≈ 营业成本 + 进项税 + 存货增加 + 应付减少 - 预付减少
- 经营活动现金流净额与净利润的关系是否合理

### 4. 现金流量异常分析

- 经营活动现金流长期为负
- 经营活动现金流与净利润严重背离
- 投资活动大额流出但无相应资产增加
- 筹资活动依赖短期借款

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 经营现金流长期为负 | 盈利能力差、回款困难 |
| 经营现金流与净利润严重背离 | 利润质量差、存在虚构收入 |
| 将筹资/投资现金流计入经营现金流 | 粉饰经营活动 |
| 受限资金未剔除 | 现金及现金等价物高估 |
