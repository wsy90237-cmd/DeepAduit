# 薪酬与人事循环审计

覆盖职工薪酬、社保公积金、股份支付等科目的审计程序。

## 审计目标

- **完整性**：所有员工和薪酬均已记录
- **准确性**：薪酬计算和分摊准确
- **截止**：薪酬计入正确期间
- **分类**：薪酬与福利、劳务费正确划分
- **列报**：股份支付、离职补偿等恰当披露

## 关键程序

### 1. 员工名册核对

- 获取人事部门员工名册
- 与财务账面薪酬发放名单核对
- 关注差异：
  - 名册有人但无薪酬（可能体外发放）
  - 名册无人但有薪酬（虚构员工）
  - 临时工/外包人员分类错误

### 2. 薪酬总额勾稽

- 账面薪酬总额 vs 个税申报总额
- 账面薪酬 vs 社保/公积金申报基数
- 人均薪酬变动分析
- 薪酬总额与产能/收入的匹配性

### 3. 社保公积金检查

- 检查是否足额缴纳社保公积金
- 核对缴费基数与薪酬总额的一致性
- 检查是否存在未缴纳的试用期员工
- 关注劳务派遣、外包人员的社保责任划分

### 4. 股份支付

- 识别股权激励计划
- 检查授予日公允价值确定
- 检查等待期/归属期的费用分摊
- 检查行权条件（服务期限、业绩条件）

### 5. 离职补偿

- 检查辞退福利的计提依据
- 检查内退人员费用处理

### 6. 薪酬截止测试

- 检查资产负债表日前后薪酬入账
- 关注年终奖、绩效奖金的预提是否合理

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 员工人数与薪酬总额不匹配 | 虚构员工、体外发放 |
| 个税申报与账面薪酬差异大 | 少代扣个税、账外薪酬 |
| 社保基数显著低于薪酬 | 少缴社保 |
| 人均薪酬异常波动 | 利润调节 |
| 大量使用劳务派遣/外包 | 规避社保、劳动关系风险 |
