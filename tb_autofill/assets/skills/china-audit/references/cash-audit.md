# 货币资金审计

依据《中国注册会计师审计准则第 1311 号》及货币资金相关审计程序执行。

## 审计目标

- **存在**：账面货币资金真实存在
- **完整性**：所有银行账户和资金余额均已记录
- **权利和义务**：资金归被审计单位所有
- **计价**：余额准确，汇率折算正确
- **列报**：受限资金（保证金、冻结资金）恰当披露

## 关键程序

### 1. 银行账户完整性核查

**获取开户清单：**
- 取得《已开立银行结算账户清单》（人民银行征信中心）
- 与账面银行账户核对，识别未入账账户
- 关注异地账户、睡眠账户、近期新开/注销账户

**异常信号：**
- 账面账户数量少于开户清单
- 存在个人卡收付公司款项
- 存在体外循环账户

### 2. 银行对账单核对

对每一银行账户：
1. 获取资产负债表日银行对账单
2. 与账面余额核对
3. 编制银行存款余额调节表
4. 对调节项目追查至期后入账情况

### 3. 银行函证

- 亲自寄送或跟函
- 函证内容：存款、借款、担保、票据、理财、信用证、远期外汇合约
- 核对回函地址与官方地址
- 对不回函实施替代程序

### 4. 现金监盘

- 突击盘点
- 上午上班前或下午下班后
- 出纳、会计主管、审计人员同时在场
- 盘点后倒推至资产负债表日

### 5. 资金流水核查

**大额资金流水：**
- 抽查资产负债表日前后大额收付款
- 关注交易对手是否异常
- 关注是否存在关联方资金占用

**异常交易识别：**
- 频繁整数金额往来
- 与个人之间的资金往来
- 与供应商/客户之间的非经营性资金往来
- 当日大额进出（过账/走单）

### 6. 受限资金检查

- 银行承兑汇票保证金
- 信用证保证金
- 冻结资金
- 定期存款质押
- 受限资金是否从现金及现金等价物中剔除

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 期末大额资金余额但借款很多 | 资金受限、存单质押、虚构资金 |
| 银行对账单与账面长期未核对 | 核算混乱、资金挪用 |
| 大量通过个人卡收付款 | 体外循环、收入不入账 |
| 频繁关联方资金拆借 | 资金占用、利益输送 |
| 期末突击回款 | 虚构回款、粉饰现金流 |
