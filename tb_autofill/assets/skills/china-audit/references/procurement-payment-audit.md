# 采购与付款循环审计

覆盖应付账款、存货、固定资产、费用等科目的审计程序。

## 审计目标

### 应付账款
- **完整性**：所有已发生的采购和应付款项均已入账（最关注）
- **存在/发生**：记录的应付账款真实存在
- **准确性**：金额和账龄准确
- **权利和义务**：负债归被审计单位承担

### 存货
- **存在**：存货真实存在
- **完整性**：所有存货均已记录
- **计价与分摊**：成本结转准确、跌价准备充分
- **权利和义务**：存货归被审计单位所有

### 固定资产
- **存在**：资产真实存在且正常使用
- **完整性**：所有资产均已入账
- **计价**：原值、折旧、减值准确
- **权利和义务**：权属清晰

## 关键程序

### 1. 采购真实性测试

从账面采购记录选样，追查至：
- 采购订单/合同
- 验收单/入库单
- 发票
- 付款审批和付款凭证

**关注异常：**
- 供应商与实际收货单位不一致
- 发票开具内容与采购内容不符
- 付款对象与供应商不一致
- 采购价格显著偏离市场价

### 2. 应付账款完整性测试

- 检查资产负债表日后收到的供应商发票
- 从验收单/入库单出发，逆查至应付账款记录
- 检查货到票未到的暂估入账
- 对主要供应商发函证

### 3. 存货监盘

- 参与期末存货盘点或执行监盘
- 抽盘：从实物到账、从账到实物
- 关注毁损、陈旧、过时存货
- 关注寄售、代管、在途存货

### 4. 存货计价测试

- 检查成本结转方法（先进先出、加权平均）
- 检查成本结转与收入匹配
- 测试存货跌价准备
- 关注可变现净值的确定依据

### 5. 固定资产审计

- 检查新增资产的审批、合同、发票、验收
- 实地盘点大额资产
- 复核折旧政策（年限、残值率、方法）
- 检查资产减值迹象和减值测试
- 关注资产权属证明

### 6. 费用截止测试

- 检查资产负债表日前后大额费用
- 检查预提费用和待摊费用
- 关注是否存在跨期费用调节利润

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 存货周转天数异常增加 | 滞销、减值未计提、成本结转延迟 |
| 应付账款长期挂账 | 隐匿收入、虚构负债 |
| 主要供应商为新成立公司 | 隐性关联方、虚构采购 |
| 采购价格显著高于市场价 | 利益输送、虚增成本 |
| 固定资产闲置率高 | 资产虚增、减值未计提 |
| 期末突击减少应付账款 | 美化流动比率 |
