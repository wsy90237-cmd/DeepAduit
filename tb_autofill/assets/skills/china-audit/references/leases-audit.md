# 租赁准则审计

依据《企业会计准则第 21 号——租赁》（2018 修订版）执行。

## 承租人会计处理

### 识别租赁

判断合同是否属于租赁或包含租赁：
- 存在一定期间
- 存在已识别资产
- 客户有权主导资产的使用并获得几乎全部经济利益

### 使用权资产

初始计量：
```
使用权资产 = 租赁负债初始金额
           + 租赁期开始日或之前支付的租赁付款额
           - 已享受的租赁激励
           + 初始直接费用
           + 复原成本现值
```

后续计量：
- 按成本模式计量
- 计提折旧（通常按租赁期与使用寿命孰短）
- 计提减值

### 租赁负债

初始计量：租赁期开始日尚未支付的租赁付款额的现值

折现率选择：
- 优先使用租赁内含利率
- 无法确定时，使用承租人增量借款利率

后续计量：
- 按摊余成本计量
- 利息费用按实际利率法确认

### 短期租赁和低价值资产租赁

- 短期租赁：租赁期不超过 12 个月
- 低价值资产租赁：全新时价值较低（通常 ≤ 5 万元）
- 可选择简化处理，不确认使用权资产和租赁负债

## 出租人会计处理

### 融资租赁
- 终止确认租赁资产
- 确认应收融资租赁款
- 确认未实现融资收益

### 经营租赁
- 保留租赁资产
- 按直线法确认租金收入

## 审计目标

- **完整性**：所有租赁合同均已识别和入账
- **准确性**：折现率、付款额、折旧摊销计算准确
- **分类**：租赁/服务正确区分，短期/低价值判断正确
- **列报**：使用权资产、租赁负债恰当列报

## 关键程序

### 1. 租赁识别

- 获取所有租赁合同清单
- 检查是否存在未入账的租赁（ especially 口头协议、框架协议）
- 判断合同是否包含租赁

### 2. 租赁负债复核

- 检查租赁付款额完整性
- 复核折现率合理性
- 重新计算现值
- 检查后续利息费用

### 3. 使用权资产复核

- 检查初始计量
- 复核折旧年限和方法
- 检查减值迹象

### 4. 租赁变更

- 检查租赁变更的会计处理
- 判断是否构成单独租赁
- 重新计量租赁负债

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 大量租赁合同未入账 | 表外融资、租赁识别不完整 |
| 折现率选择不合理 | 租赁负债金额失真 |
| 使用权资产折旧年限过长 | 费用少计、利润高估 |
| 租赁/服务分类错误 | 资产和负债错报 |
