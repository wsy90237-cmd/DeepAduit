# 合并报表审计

依据《企业会计准则第 33 号——合并财务报表》执行。

## 合并范围判断

### 控制三要素

1. **拥有对被投资方的权力**
   - 持有半数以上表决权
   - 通过协议拥有半数以上表决权
   - 有权任免多数董事会成员
   - 在董事会拥有多数表决权

2. **参与被投资方的相关活动而享有可变回报**
   - 股利、利润分配
   - 资本增值
   - 其他经济利益

3. **有能力运用权力影响回报金额**
   - 实质性权利而非保护性权利
   - 考虑潜在表决权

## 审计目标

- **完整性**：所有应合并子公司均已纳入合并范围
- **准确性**：合并抵销分录正确
- **一致性**：会计政策统一
- **列报**：少数股东权益、商誉等恰当列报

## 关键程序

### 1. 合并范围检查

- 获取子公司清单及持股比例
- 检查公司章程、股东协议
- 判断控制是否存在
- 关注结构化主体（如信托、基金、合伙企业）

### 2. 子公司报表审计

- 获取经审计的子公司财务报表
- 统一会计政策和会计期间
- 检查外币报表折算

### 3. 合并抵销

**长期股权投资与所有者权益抵销：**
```
借：实收资本
    资本公积
    盈余公积
    未分配利润
    商誉
贷：长期股权投资
    少数股东权益
```

**内部往来抵销：**
- 应收账款与应付账款
- 其他应收款与其他应付款
- 预收账款与预付账款

**内部交易抵销：**
- 内部销售收入与成本
- 未实现内部销售损益（存货、固定资产）
- 内部投资收益

**内部现金流抵销：**
- 集团内部资金往来

### 4. 商誉减值测试

- 识别商誉相关资产组
- 评估未来现金流量预测
- 复核折现率
- 检查减值迹象

### 5. 少数股东权益

- 复核少数股东权益计算
- 检查少数股东损益

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 应合并子公司未合并 | 隐瞒亏损、粉饰报表 |
| 内部交易未充分抵销 | 收入和利润虚增 |
| 商誉减值测试激进 | 商誉减值准备不足 |
| 会计政策不统一 | 合并数据不可比 |
| 结构化主体未纳入合并 | 表外融资、风险隐藏 |
