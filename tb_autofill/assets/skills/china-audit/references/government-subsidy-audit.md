# 政府补助审计

依据《企业会计准则第 16 号——政府补助》执行。

## 政府补助分类

### 与资产相关的政府补助
- 用于购建或以其他方式形成长期资产
- 会计处理：
  - 总额法：确认为递延收益，在资产使用寿命内分期计入损益
  - 净额法：冲减相关资产账面价值

### 与收益相关的政府补助
- 补偿企业已发生或即将发生的相关成本费用或损失
- 会计处理：
  - 补偿以后期间：先确认为递延收益，在确认相关费用时计入损益
  - 补偿已发生费用：直接计入当期损益或冲减相关成本

## 审计目标

- **存在/发生**：政府补助真实收到且符合条件
- **完整性**：所有政府补助均已入账和披露
- **准确性**：金额、分类、摊销/确认期间准确
- **分类**：与资产相关/与收益相关划分正确
- **列报**：是否属于非经常性损益恰当披露

## 关键程序

### 1. 获取补助文件

- 政府补助批复文件
- 补助协议/合同
- 资金到账凭证
- 项目验收报告（如适用）

### 2. 检查补助性质

判断是否为政府补助：
- 来源于政府的经济资源
- 无偿性
- 有指定用途

**不属于政府补助的情形：**
- 政府作为所有者投入的资本
- 增值税出口退税
- 政府代付给第三方的款项

### 3. 检查分类准确性

- 与资产相关：是否用于构建长期资产
- 与收益相关：补偿已发生还是未来期间
- 区分与日常活动相关/无关

### 4. 检查会计处理

**总额法：**
- 收到时确认递延收益
- 资产达到预定可使用状态后开始摊销
- 摊销年限与资产折旧年限一致

**净额法：**
- 冲减资产账面价值
- 相应减少折旧费用

### 5. 检查退回情况

- 未满足补助条件需退回的，是否冲减递延收益或计入当期损益
- 已计入损益的补助退回，是否追溯调整

### 6. 披露检查

- 政府补助种类、金额和列报项目
- 计入当期损益的政府补助金额
- 本期退回的政府补助金额及原因

## 高风险信号

| 信号 | 可能问题 |
|-----|---------|
| 政府补助占净利润比例过高 | 利润依赖补助，可持续性差 |
| 缺少正式批复文件 | 补助真实性存疑 |
| 补助分类随意 | 利润调节 |
| 摊销年限与资产使用年限不一致 | 收益确认期间错误 |
| 补助退回未处理 | 负债或损益错报 |
