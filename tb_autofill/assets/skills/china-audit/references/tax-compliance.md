# 税务合规检查

依据《税收征收管理法》及增值税、企业所得税、个人所得税相关法律法规执行。

## 增值税检查

### 销项税额核对
- 获取增值税纳税申报表
- 与账面销项税额勾稽
- 检查税率适用：13%、9%、6%、0%、简易计税 3%/5%

### 进项税额核对
- 抵扣凭证合规性（专票、海关缴款书、农产品收购发票）
- 不得抵扣情形：简易计税、免税项目、集体福利、个人消费、贷款/餐饮/居民日常/娱乐服务
- 进项转出是否足额

### 增值税与收入勾稽
```
理论销项税额 ≈ 应税收入 × 适用税率
差异原因：视同销售、纳税义务时间与收入确认时间差异、简易计税、免税收入
```

## 企业所得税检查

### 应纳税所得额调整

| 调整项目 | 常见内容 | 方向 |
|---------|---------|------|
| 收入类 | 视同销售、不征税/免税收入 | 调增/调减 |
| 扣除类 | 业务招待费 60% 且 ≤ 营收 0.5%、广告费 ≤ 15%/30%、公益捐赠 ≤ 利润总额 12% | 调增 |
| 资产类 | 加速折旧、减值准备、摊销年限 | 调增/调减 |
| 特殊事项 | 关联交易定价、研发费用加计扣除 | 调减 |

### 研发费用加计扣除
- 核实研发活动范围
- 区分费用化与资本化
- 委托研发 80% 限额
- 制造业/科技型中小企业 100% 加计扣除

### 小型微利企业优惠
- 应纳税所得额 ≤ 300 万元
- 从业人数 ≤ 300 人
- 资产总额 ≤ 5000 万元

### 递延所得税
- 暂时性差异识别与计量

## 个人所得税检查

- 工资薪金全员全额扣缴申报
- 账面薪酬与申报数据一致性
- 专项附加扣除证明材料
- 股权激励个税处理
- 劳务报酬、股息红利、股权转让个税

## 其他税费

- 城建税、教育费附加、地方教育附加
- 印花税（2022 年 7 月 1 日起新《印花税法》）
- 房产税、土地使用税
- 契税、土地增值税（如适用）

## 税务风险信号

| 信号 | 可能问题 |
|-----|---------|
| 增值税税负率显著低于行业均值 | 隐匿收入、虚增进项 |
| 所得税贡献率异常 | 虚增成本、转移定价 |
| 长期大额应交税费贷方余额 | 欠缴税款 |
| 频繁更正申报 | 核算基础薄弱或调节 |
| 大量异常凭证 | 虚开发票风险 |
