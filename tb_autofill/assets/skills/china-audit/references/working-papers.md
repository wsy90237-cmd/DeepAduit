# 审计工作底稿编制

依据《中国注册会计师审计准则第 1131 号——审计工作底稿》执行。

## 底稿要素

每份底稿至少包含：
- 被审计单位名称
- 审计项目/科目
- 审计期间
- 编制人、复核人签名及日期
- 审计目标与程序
- 审计过程记录
- 审计结论
- 交叉索引

## 底稿分类

### 永久性档案（A 类）
- A1 基本情况
- A2 营业执照、章程
- A3 重要合同
- A4 历史审计报告

### 当期档案（B 类）
- B1 风险评估与审计策略
- B2 重要性水平
- B3 控制测试
- B4 实质性程序（按科目）

### 完成阶段（C 类）
- C1 审计差异调整汇总
- C2 试算平衡表
- C3 管理层声明书
- C4 审计报告

## 关键底稿

### 试算平衡表
- 未审数 → 审计调整 → 审定数
- 调整类型：审计调整、重分类调整、抵销调整

### 审计差异汇总表
- 建议调整：超过临界值
- 不建议调整：未超过临界值
- 客户不同意调整：评估审计意见影响

### 函证控制底稿
- 发函/回函控制表
- 差异调查记录

## 复核要点

- 程序执行到位
- 证据充分适当
- 结论与证据一致
- 计算准确

## 输出模板

