# 审核问询的拆解与答复

## 一、先拆问题，再动笔

问询函的每个问题都由四层构成，答复必须逐层回应，缺一层即被追问：

| 层 | 问询函的典型表述 | 答复要做的事 |
|---|---|---|
| 事实层 | "请说明报告期内……的具体情况" | 用数据把事实讲清：金额、比例、对象、期间、变动 |
| 依据层 | "请说明……的依据及合理性" | 给出准则依据、合同条款、行业惯例、可比公司数据 |
| 程序层 | "请保荐机构、申报会计师核查并发表明确意见" | 列明已执行的核查程序、范围、样本、覆盖率 |
| 结论层 | "请说明是否……" | 给出明确结论，不含糊、不回避 |

只答事实层是初学者最常见的失误：问询人真正想知道的是"这个数可不可信"，而可信度来自程序层。

## 二、答复的标准结构

```
一、事实情况
   （一）业务背景与交易安排
   （二）报告期数据（表格化，分年度/分产品/分客户）
二、原因分析
   （一）量化拆解（量、价、结构、政策）
   （二）与同行业/历史期间对比
三、核查程序与核查意见
   （一）核查范围与方法（样本量、覆盖率）
   （二）具体程序及发现
   （三）核查结论
四、补充披露
   拟在招股说明书"第X节"补充披露如下：……
```

第四节不可省略：绝大多数问询都要求"补充披露"，须给出拟补充的具体文字与位置，而非仅口头说明。

## 三、常见问法分类与应答要点

### 收入真实性

- 必答：分模式收入、主要客户、合同条款、控制权转移依据、函证与走访覆盖、期后回款。
- 加分：终端销售穿透、物流与能耗交叉验证、海关数据核对（外销）、同行业增速对比。

### 客户集中度

- 必答：集中度数据、行业集中度背景、客户稳定性（合作年限、份额）、替代难度、在手订单、新客户拓展。
- 关键论证：集中是行业属性所致而非发行人竞争力不足；可用"下游前五大厂商市占率"数据支撑。
- 风险披露：主要客户引入第二供应商、自研替代、采购政策变化的影响与量化。

### 收入确认政策

- 必答：各模式的控制权转移时点、判断依据、单据、与同行业是否一致。
- 高风险点：寄售、时段法、总额法/净额法、验收条款复杂、存在退换货权。

### 毛利率异常

- 必答：分层拆解、可比公司口径调整、单位成本分解、期后验证。
- 见 `04-margin-cost.md`。

### 资金流水与关联方

- 必答：核查范围（账户清单、人员范围、期间）、异常标准、发现的异常及处理、结论。
- 见 `05-cashflow-related-party.md`。

### 会计差错更正与申报报表差异

- 必答：差异明细、形成原因、性质（差错/政策变更/估计变更）、对各期净资产与净利润的影响、是否履行审批、是否影响发行条件。
- 关键：区分"差错更正"与"政策变更"，差错更正须说明内控缺陷及整改；调整金额占净利润比例较大的，可能影响申报时点。

### 内部控制

- 必答：缺陷识别与分级、整改措施、整改后运行期间、是否构成重大缺陷、对发行条件的影响。
- 报告期内存在重大缺陷的，须说明整改完成时点及整改后至少运行一个完整会计期间。

### 募投项目

- 必答：项目必要性、产能消化（现有产能利用率、在手订单、市场空间）、新增折旧摊销对业绩的影响（量化）、效益测算的假设与依据。
- 常见披露：募投达产后新增折旧摊销与人员薪酬合计金额，占预计新增营业收入与净利润的比例。

### 对赌与特殊投资条款

- 必答：条款内容、签署与解除时间、是否彻底解除、是否存在恢复条款、是否影响股权清晰。
- 通常要求申报前清理完毕，或至少确保不与市值挂钩、不导致控制权变更。

## 四、答复的表述纪律

1. **量化优先**：能算的都给数，避免"较大""显著""有所提升"。
2. **对比有锚**：与历史期间、同行业、合同约定、市场公开数据对比。
3. **程序可核**：写明"抽查 X 笔、金额 Y 万元、占该类交易 Z%"，而非"进行了抽查"。
4. **结论不越证据**：程序只覆盖 60% 的，结论不得表述为"已充分核查全部交易"。
5. **不承诺无法履行的事**：如"未来不再发生关联交易"，应改为"按公允价格进行并履行决策程序"。
6. **前后一致**：同一数据在招股书、问询回复、专项说明中必须一致，口径变更须说明。
7. **不虚构依据**：引用规则须确有其文；不确定时描述规则主题，不写编号。

## 五、常见踩坑清单

1. 答非所问：问"是否具备可持续性"，答"公司技术领先"。
2. 只给结论不给过程：直接写"经核查，收入真实"。
3. 程序与结论不匹配：样本覆盖 30% 却结论"不存在异常"。
4. 数据前后矛盾：招股书与回复中的客户名单、金额、比例不一致。
5. 过度承诺：承诺未来三年毛利率不低于某水平。
6. 回避风险：不披露已知的不利趋势（如主要客户已引入第二供应商）。
7. 补充披露缺位：只说"将补充披露"，未给具体文字。
8. 用行业惯例替代依据：以"同行都这么做"作为会计处理的唯一理由。
9. 口径混用：同一指标在不同章节采用不同计算方式（如毛利率是否含运费）。
10. 忽略期后事项：报告期后发生的客户流失、价格下调未在回复中反映。

## 六、多轮问询的应对

- 第二轮问询通常针对第一轮答复中的薄弱点，须先自查首轮答复是否存在"程序不足、数据不支撑、结论过强"。
- 若事实发生变化（如期后业绩下滑），须主动更新，不得沿用旧口径。
- 同一问题被反复问及，往往意味着答复未触及实质，应改变论证角度而非重复表述。

## 七、穿透不通过时的处置路径

核查结论可能指向不利事实，此时不能只写"存在风险"，必须给出处置选项与触发条件。决策顺序如下：

| 情形 | 处置选项 | 判断要点 |
|---|---|---|
| 交易真实、仅定价或结构存在瑕疵 | 补充核查 + 补充披露 + 量化风险 | 不影响发行条件时，用数据与承诺闭环 |
| 关联关系成立但交易真实 | 认定为关联方、补充披露、补履行决策程序、出具规范承诺 | 关注是否影响独立性、是否持续发生 |
| 内控缺陷明确且可整改 | 整改 + 运行满一个完整期间 + 出具整改报告 | 报告期内重大缺陷通常推迟申报时点 |
| 收入真实性无法证实 | 调整账务并重新审计、或剔除相关收入后重算指标 | 剔除后是否仍满足所选上市标准 |
| 财务数据存在系统性失真 | 撤回申报、追加审计、更换报告期后重新申报 | 涉及处罚风险，须同步评估中介机构责任 |

操作要点：
1. **先算指标**：任何调整都要即时测算对营业收入、净利润、净资产收益率、上市标准、板块定位指标的影响，用数字决定走哪条路。
2. **给出时点**：调整后需运行多久、需补充几期数据，形成明确的申报时间表。
3. **留痕**：与发行人、保荐机构就处置方案形成书面沟通记录，避免后续责任不清。
4. **不隐瞒**：不得以"已充分披露风险"替代事实认定；披露不改变事实的定性。
