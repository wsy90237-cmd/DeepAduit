# 板块差异：披露结构与上市标准

## 一、文件性质

| 板块 | 文件名称 | 审核/注册 |
|---|---|---|
| 沪市主板（上交所）/ 深市主板（深交所） | 首次公开发行股票并在主板上市招股说明书 | 交易所审核 + 证监会注册 |
| 科创板 | 首次公开发行股票并在科创板上市招股说明书 | 上交所审核 + 证监会注册 |
| 创业板 | 首次公开发行股票并在创业板上市招股说明书 | 深交所审核 + 证监会注册 |
| 北交所 | 招股说明书（向不特定合格投资者公开发行） | 北交所审核 + 证监会注册，须为在新三板挂牌满一定期限的创新层公司 |
| 新三板 | 公开转让说明书 | 全国股转公司审核 |
| 港股 | 上市文件 / 申请版本（Application Proof） | 联交所 + 香港证监会 |

申报稿均须标注"申报稿"，并声明"不具有据以发行股票的法律效力，仅供预先披露之用"。

## 二、章节结构

### A 股招股说明书（主板/科创板/创业板通用骨架）

第一节 释义 → 第二节 概览（含重大事项提示、特别风险提示、发行概况、主要财务数据、上市标准）→ 第三节 风险因素 → 第四节 发行人基本情况 → 第五节 业务与技术 → 第六节 财务会计信息与管理层分析 → 第七节 募集资金运用与未来发展规划 → 第八节 公司治理与独立性 → 第九节 投资者保护 → 第十节 其他重要事项 → 第十一节 声明 → 第十二节 附件

**财务会计信息与管理层分析**是财务核查的核心章节，通常占全文 30%–40%，内容见 `08-disclosure-norms.md`。

### 北交所招股说明书

骨架与 A 股相近，但前置"发行人挂牌期间的基本情况"（挂牌时间、地点、挂牌期间受处罚情况、定向发行情况），并设"发行人自身的创新特征"专节。财务章节更紧凑。

### 新三板公开转让说明书

结构明显不同：基本情况 → 公司业务 → 公司治理 → 财务会计信息 → 附件。不设"募集资金运用"（无公开发行），不设"投资者保护"。财务信息深度低于招股说明书，但收入确认政策、关联交易、资金占用仍须充分披露。

### 港股申请版本

概要 → 风险因素 → 行业概览 → 历史、发展及公司架构 → 业务 → 与控股股东的关系 → 关连交易 → 董事及高级管理层 → 主要股东 → 股本 → 财务资料 → 未来计划及所得款项用途 → 发行架构 → 附录一 会计师报告 → 附录二 未经审计备考财务资料 → 附录三 公司章程 → 附录四 法定及一般资料。

特征：
- 全文含大量「[編纂]」（即 [Redacted]）占位，待定价与发行规模确定后补充；
- 财务数据主体在**附录一会计师报告**，而非正文；
- 设"与单一最大股东集团的关系"专章，论证独立性；
- 采用 IFRS（收入按 IFRS 15，金融工具按 IFRS 9）；
- 披露非 IFRS 财务指标（如经调整净利润），须与 IFRS 指标调节；
- 行业数据通常引用弗若斯特沙利文等第三方顾问报告，并注明其独立性。

## 三、上市标准

- **主板**：以净利润、营业收入、现金流、股本等组合指标为主，强调规模与稳定性。
- **科创板**：多套标准并存，允许未盈利企业上市，核心是"科创属性"（研发投入占比、发明专利数量、营收增速、技术先进性）。申报时须专节论证符合科创板定位与科创属性指标。
- **创业板**：定位"成长型创新创业企业"（三创四新），须论证符合创业板定位指标；常见标准为"预计市值不低于 15 亿元，最近一年净利润为正且营业收入不低于 4 亿元"一类组合。
- **北交所**：多套市值+财务指标组合，含"预计市值 + 净利润""预计市值 + 营业收入 + 经营活动现金流""预计市值 + 营业收入 + 研发投入"等，适配中小企业。
- **新三板**：无公开发行，挂牌条件以持续经营能力、治理规范为主。

选择标准时须同时测算：**若采用净额法核算收入、扣除特定收入后，是否仍满足所选标准**。收入口径调整导致不满足标准的，须改选标准或调整申报时点。

## 四、定位指标的财务影响

- 科创属性：研发投入占营业收入比例（近三年累计或最近一年）、研发人员占比、发明专利数量。研发费用归集不实将直接影响该指标，是问询重点。
- 创业板定位：营业收入复合增长率、研发投入、研发人员。同样受收入口径与研发费用归集影响。
- 因此，**收入确认方法（总额/净额）与研发费用归集**两项，同时影响会计利润与板块定位指标，须在申报前统筹测算。

## 五、风险因素的编排差异

A 股：按"与发行人相关的风险"（经营、财务、技术、募投）与"与本次发行相关的风险"分类，特别风险提示置于第二节概览开头，逐条命名（如"客户集中度较高的风险""原材料供应和价格波动风险"）。

港股：按"有关我们业务及行业的风险""有关[编纂]的风险"分类，条目更多、表述更长，且大量使用"可能对业务、财务状况及经营业绩造成重大不利影响"的固定句式。

风险条目必须**具体到发行人自身**，不得写成行业通用风险；每条风险应说明影响机制与可能的量化后果。

## 六、跨板比较的注意点

- 北交所与新三板公司多为中小企业，客户集中度高、内控基础薄弱，问询更关注规范性与真实性；主板公司规模大，问询更关注持续盈利能力与同业竞争。
- 科创板未盈利企业须重点论证"持续经营能力"与"预计可实现盈利的依据与假设"，招股书设专节披露前瞻性信息。
- 港股与 A 股双重申报的，须注意会计准则差异（CAS 与 IFRS）、关联方定义差异（关连人士范围更宽）、独立性论证口径差异；两地披露的财务数据须能相互调节。
