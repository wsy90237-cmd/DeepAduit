# 应收账款与存货核查

## 一、应收账款

### 核查要点

1. **余额与变动**：报告期各期末余额、占营业收入比例、周转率（次/年），与同行业对比；收入增速与应收增速的背离须解释。
2. **账龄结构**：1 年以内、1–2 年、2–3 年、3 年以上占比及变动；账龄划分须以发票或合同约定的收款权到期日为基础，不得按"最后发生额法"人为缩短账龄。
3. **坏账准备政策**：组合计提的比例（通常按账龄组合）与同行业可比公司逐档对比；单项计提的客户、金额、原因、计提比例及依据。
4. **预期信用损失模型**：采用三阶段模型的，说明历史损失率测算过程、前瞻性调整依据；模型参数变更须作为会计估计变更披露。
5. **期后回款**：这是最关键的一项。须取得**各期末**应收账款在次年（或申报前）的回款情况，计算回款比例；回款比例偏低或集中于近期回款的，须追加程序并说明。
6. **客户信用与集中度**：前五大欠款客户的经营状况、是否与发行人存在关联关系、是否出现逾期。
7. **核销与转销**：报告期内核销的应收账款，是否履行内部审批、是否符合税法资产损失扣除条件。

### 核查程序清单

- 取得应收账款明细表，与总账、报表核对；
- 抽取样本函证期末余额，对未回函执行替代程序（合同、发票、签收单、期后回款）；
- 检查期后回款：取得期后银行流水，逐笔核对应收账款回收，计算覆盖率；
- 检查账龄计算的准确性，重新计算账龄分布；
- 评价坏账准备计提政策的一贯性与合理性，重新计算组合计提金额；
- 对单项计提客户，取得其工商信息、诉讼与执行记录、访谈记录；
- 对关联方欠款单独列示并核查形成原因。

### 常见异常

- 期末余额激增、期后大额回款后又新增欠款（滚动占用）；
- 应收账龄与客户实际结算周期不符；
- 坏账准备计提比例显著低于同行业而无合理解释；
- 以票据、保理、应收账款质押等方式提前回款，实质未收回；
- 客户与发行人存在未披露的关联关系。

## 二、存货

### 核查要点

1. **监盘**：覆盖全部仓库（自有仓、租赁仓、外库、第三方代管、在途、寄售于客户处），监盘比例（金额与数量）须披露；对存放在第三方或客户处的存货，执行函证或现场查看。
2. **计价测试**：对主要原材料、在产品、库存商品执行计价测试，验证成本归集与结转的准确性。
3. **跌价准备**：可变现净值的确定依据（估计售价、至完工估计成本、销售费用、相关税费）；库龄分析与呆滞料清单；跌价准备计提比例与同行业对比；期后销售价格是否支持估计售价。
4. **发出商品**：金额、账龄、对应客户与订单；对发出商品执行函证或期后结转检查，验证是否已实际交付。
5. **存货周转率**：与同行业对比，异常偏低须解释备货政策与订单支撑。
6. **成本完整性**：结合能耗、人工、产量数据验证成本归集是否完整，防止少转成本虚增利润。

### 核查程序清单

- 制定监盘计划，覆盖金额 70% 以上的存货，记录盘点差异及处理；
- 对存货执行计价测试，检查采购发票、入库单、领料单、工时记录、制造费用分配表；
- 取得库龄表，重新计算库龄，检查呆滞存货；
- 评价跌价准备计提方法与参数，重新计算；比较期后实际售价与估计售价；
- 对发出商品函证或检查期后结转收入凭证；
- 结合产能、能耗、人工与产量的匹配性执行分析性程序。

### 常见异常

- 存货余额与产能、订单、销售规模不匹配；
- 存货周转率持续下降而跌价准备未同步计提；
- 在产品金额异常，或长期挂账不结转；
- 存货存放于关联方或不明第三方处，无法监盘；
- 存货明细中出现与主营业务无关的品类。

## 三、合同资产与合同负债

- 合同资产：收款权尚未成为无条件权利（如尚需验收、尚需运行一段时间）的部分；披露账面余额、减值准备、账龄（一般不计算账龄，转为应收账款后才计算）、转入应收账款的时点与金额。
- 合同负债：预收客户款项且尚未履约的部分；关注大额合同负债对应的订单与履约安排，防止以预收款虚增现金流。
- 同一合同下的合同资产与合同负债应分别列示，不得随意抵销，除非具有法定抵销权且拟净额结算。

## 四、答复口径示例

问：应收账款余额增长较快，坏账准备计提是否充分？

合格答复结构：
1. 余额增长与收入增长、信用政策、客户结构变化的匹配关系（量化）。
2. 账龄结构与同行业对比，说明 1 年以内占比、逾期比例。
3. 期后回款情况：截至某时点已回款金额及比例，逐期列示。
4. 坏账计提政策与同行业逐档比较，说明差异原因。
5. 单项计提客户的经营状况与减值依据。
6. 风险提示：若主要客户付款能力恶化，对业绩的影响金额。

不得仅以"客户均为大型国企、信用良好"作为结论。
