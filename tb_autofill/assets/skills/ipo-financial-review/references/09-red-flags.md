# 财务舞弊迹象与高频追问

## 一、迹象清单（按环节）

### 收入端

1. 期末收入占比异常，第四季度或最后一个月收入显著高于历史与同行业。
2. 收入增长与增值税申报、开票数据、海关出口数据不匹配。
3. 新增客户成立时间短、注册资本小、参保人数少，却贡献大额收入。
4. 客户与供应商重叠，或客户为发行人前员工、关联方控制。
5. 销售价格显著偏离同期其他客户，且无质量、账期、批量差异。
6. 收入确认单据存在连号、同一笔迹、事后补签、无物流记录。
7. 期后大额退货、折让，或收入在期后大额冲回。
8. 经销商库存持续增长而终端销售未见同步。
9. 收入增长但运费、包装费、能耗未同步增长。
10. 外销收入无报关数据支撑，或报关金额与账面差异未解释。

### 成本与费用端

1. 毛利率显著高于同行业且无法归因于技术、品牌、成本结构。
2. 单位成本持续下降而原材料价格未下降。
3. 产能利用率下降但单位固定成本未上升。
4. 研发费用与研发项目、专利产出、研发人员数量不匹配；生产人员薪酬混入研发费用。
5. 销售费用率显著低于同行业，且无客户集中或区域集中的合理说明。
6. 关联方或实际控制人代垫成本费用（房租、水电、人工、运费）。
7. 期末突击计提或冲回费用，调节利润。

### 资产端

1. 应收账款增速持续高于收入增速，或账龄结构恶化而坏账准备未同步计提。
2. 存货余额与产能、订单、销售规模不匹配；存货周转率下降而跌价准备未提。
3. 在建工程长期挂账不转固，或转固时点异常推迟以规避折旧。
4. 在建工程金额与工程量、监理报告不符。
5. 商誉、长期股权投资减值测试参数明显乐观。
6. 货币资金余额高但利息收入低，或存在大额受限资金未披露。
7. 其他应收款、预付款项中存在关联方或不明对手方大额余额。

### 资金端

1. 存在未披露银行账户。
2. 大额资金在关联方之间频繁往来，无商业实质。
3. 客户回款由第三方（个人、关联方、客户员工）支付，无三方协议。
4. 银行流水显示资金当天进当天出、整数金额、闭环回流。
5. 存在转贷（受托支付资金回流）、无真实背景票据贴现。
6. 实际控制人个人卡收取货款或支付费用。

### 治理与内控端

1. 财务负责人、审计机构在报告期内频繁更换。
2. 内部控制存在重大缺陷且整改时间不足。
3. 关联交易决策程序缺失，或关联方识别长期遗漏。
4. 存在体外资金循环、账外账。
5. 员工人数与社保缴纳人数差异大（可能少计人工成本）。

## 二、高频追问清单

按出现频率排列，可在复核底稿时逐条对照：

1. 收入确认政策是否符合准则、是否与同行业一致；各模式控制权转移时点及依据。
2. 客户集中度高的原因、客户稳定性、是否存在重大依赖。
3. 毛利率与同行业差异的原因及合理性，是否可持续。
4. 应收账款期后回款情况、坏账准备计提是否充分。
5. 存货跌价准备计提是否充分，是否存在呆滞存货。
6. 关联方是否完整披露，关联交易定价是否公允。
7. 是否存在资金占用、体外资金循环、转贷、票据融资。
8. 第三方回款的原因、比例、是否影响收入真实性。
9. 股份支付的公允价值确定依据、摊销期间、是否涉及实际控制人。
10. 研发费用归集是否准确，是否满足资本化条件，是否影响科创属性指标。
11. 税收优惠的可持续性，是否对税收优惠存在重大依赖。
12. 申报报表与原始报表差异的原因与性质。
13. 内部控制是否有效，是否存在重大缺陷。
14. 募投项目的必要性、产能消化能力、新增折旧对业绩的影响。
15. 对赌条款是否彻底清理，是否存在恢复条款或潜在控制权变动。
16. 持续经营能力，尤其未盈利企业的扭亏路径与依据。
17. 期后经营情况是否发生重大不利变化。
18. 收入与现金流背离的原因。
19. 主要客户与供应商是否与发行人存在未披露的关联关系。
20. 是否存在通过关联方非关联化规避披露的情形。

## 三、关联方非关联化的识别

典型手法：报告期内将关联方股权转让给"无关第三方"（实为代持或存在其他利益安排），交易随之转为非关联交易。

核查要点：
- 股权受让方的资金来源（是否来自实际控制人）；
- 受让方与发行人及其关键人员的历史关系（同乡、同学、前员工、亲属）；
- 转让后交易条件是否发生实质变化（价格、账期、结算方式）；
- 受让方的经营实质（是否有人员、场地、其他客户）；
- 资金流水是否存在回流。

## 四、复核底稿时的判断标准

对每一项异常，依次问四个问题：

1. **能否解释**：项目组是否已识别该异常？
2. **解释是否有证据**：支持文件是否为外部证据，而非管理层说明？
3. **证据是否覆盖**：样本是否覆盖异常的全部或主体部分？
4. **结论是否匹配**：结论的强度是否与证据强度相称？

四问中任一为否，即为核查缺口，须补充程序或调整结论表述。

## 五、边界

- 迹象不等于结论。发现迹象后的正确动作是追加程序，而非直接认定舞弊。
- 涉及可能的舞弊，须评估对财务报表整体、审计意见类型、内部控制意见、申报可行性的影响，并按规定履行沟通与报告程序。
- 本清单用于风险识别与底稿复核，不替代职业判断与必要的法律意见。
